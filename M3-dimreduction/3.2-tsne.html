M3.2 · DIMENSIONALITY REDUCTION

t-SNE 的機率擴散

t-SNE: Probabilistic Embedding

SNE → t-SNE 的核心修正。Perplexity 在量什麼？為什麼 t 分布解決了 SNE 的 crowding problem？

SNE → t-SNE's key fix. What perplexity measures. Why t-distribution solved SNE's crowding problem.

直覺 / Intuition

用「機率」描述鄰近關係

Probability-based neighborhood

t-SNE 不直接保留距離，而是保留「鄰居機率」：在高維空間裡 $i, j$ 是鄰居的機率，跟在 2D 嵌入空間中是鄰居的機率，要盡量一致。

t-SNE preserves neighborhood probabilities: probability that $i, j$ are neighbors in high-D ≈ probability in 2D embedding.

核心數學 / Math

高維空間的鄰居機率

High-D neighbor probability

$$p_{j|i} = \frac{\exp(-\|x_i - x_j\|^2 / 2\sigma_i^2)}{\sum_{k \neq i} \exp(-\|x_i - x_k\|^2 / 2\sigma_i^2)}, \quad p_{ij} = \frac{p_{j|i} + p_{i|j}}{2n}$$
用高斯核以 $x_i$ 為中心估計鄰居機率，對稱化後得 $p_{ij}$
Gaussian kernel centered at $x_i$, symmetrized to $p_{ij}$

Perplexity 的數學意義— what it measures

$$\text{Perp}(P_i) = 2^{H(P_i)}, \quad H(P_i) = -\sum_j p_{j|i} \log_2 p_{j|i}$$

解讀：「每個點的『有效鄰居數』」。Perplexity = 30 表示每個點被視為跟約 30 個其他點是「鄰居」。
$\sigma_i$ 是用二分搜尋讓 $\text{Perp}(P_i) = $ 使用者設定值（典型 5-50）。

Interpretation: "effective number of neighbors". Perp = 30 → each point treats ~30 others as neighbors. $\sigma_i$ is binary-searched so $\text{Perp}(P_i) = $ user value.

低維空間：為什麼用 t 分布？

Why t-distribution in low-D?

$$q_{ij} = \frac{(1 + \|y_i - y_j\|^2)^{-1}}{\sum_{k \neq l} (1 + \|y_k - y_l\|^2)^{-1}}$$
$(1+r^2)^{-1}$ 是自由度 = 1 的 Student-t 分布核（Cauchy）
$(1+r^2)^{-1}$ is the Student-t kernel with df=1 (Cauchy)

關鍵：t 分布尾巴比高斯重很多。在 2D 用高斯（SNE 原版）會出現「crowding problem」——遠距離的點被擠在一起。t 分布讓「中等距離」的點獲得較大斥力，幫不同 cluster 分開。

Key: t-distribution has much heavier tails than Gaussian. Plain SNE (Gaussian in 2D) suffers from "crowding". t-tails provide stronger repulsion at medium distances, separating clusters.

KL 目標函數與梯度objective and gradient

$$C = \text{KL}(P \,\|\, Q) = \sum_{i \neq j} p_{ij} \log \frac{p_{ij}}{q_{ij}}$$ $$\frac{\partial C}{\partial y_i} = 4 \sum_{j} (p_{ij} - q_{ij})(y_i - y_j)(1 + \|y_i - y_j\|^2)^{-1}$$

用梯度下降優化。$(p_{ij}-q_{ij})$ 是「該靠近還是該推開」的訊號。

Optimized via gradient descent. $(p_{ij}-q_{ij})$ signals attraction vs repulsion.

Barnes-Hut 加速acceleration

每步梯度是 $O(n^2)$。Barnes-Hut 用 quadtree 把遠處的點視為「一團」近似，降到 $O(n \log n)$。

Naive gradient is $O(n^2)$. Barnes-Hut uses quadtrees to approximate distant clusters, reducing to $O(n \log n)$.

演算法 / Algorithm
# Input: X (n × d), perplexity p # Output: Y (n × 2) # 1. for each i: binary search σ_i so that Perp(P_i) = p # 2. compute p_ij from σ_i # 3. Y ← random_normal(0, 0.0001, (n, 2)) # tiny init # 4. for t = 1 ... T: compute q_ij from current Y compute gradient ∂C/∂y_i Y ← Y - η · gradient + momentum # early exaggeration: multiply p_ij by 4 for first 250 iters
注意事項 / Caveats
t-SNE 的五大陷阱（Wattenberg 2016） 5 t-SNE pitfalls (Wattenberg 2016)
  1. 群之間的距離無意義——只看誰跟誰是鄰居
  2. 群的大小無意義——t-SNE 會把所有群展開到差不多大
  3. 隨機性高——不同 seed 看起來不同
  4. perplexity 影響大——5 跟 50 結果差很多
  5. 不要過度詮釋 2D 視覺——它不是真實結構
  1. Cluster distances are meaningless — only neighborhoods matter
  2. Cluster sizes are meaningless — t-SNE inflates all to similar size
  3. Highly stochastic — different seeds, different views
  4. Perplexity matters a lot — 5 vs 50 yield very different layouts
  5. Don't over-interpret 2D — it's not "real" structure
