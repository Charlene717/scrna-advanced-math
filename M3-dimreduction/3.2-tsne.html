§0 · 故事開場 / STORY

想像你在一場擠擁的舞會

Imagine you're at a crowded ballroom

舞池有 200 個人，你想知道「誰跟你關係好」。如果你有整個立體三維空間可以走動（樓上樓下、前後左右）， 你可以站在 5 個朋友的中間——他們圍著你，每人都恰好等距。

但現在管理員說：「請大家排成2D 平面。」你想保持「我跟 5 個朋友等距」的關係—— 但 2D 平面上，最多只能放 3 個朋友均勻圍著你（正三角形的頂點），第 4 個就破壞了等距。 還剩兩個朋友怎麼辦？只好被推到「比較遠」的位置——這就是「擠擁問題 (crowding problem)」。

t-SNE 的答案：與其硬把所有鄰居都擠進 2D，不如允許他們「離得稍遠」一些。 用 Student-t 分布取代 Gaussian 作為低維距離核—— t 分布的「長尾」讓「中等距離」獲得比 Gaussian 更高的機率， 變相給了被擠開的朋友一個「安全距離」。

You're in a ballroom with 200 people. In 3D space, you can stand at the center of 5 equidistant friends. But if the manager says "everyone to 2D"... a flat plane fits only 3 equidistant points around you (triangle vertices). The other 2 friends must be pushed farther — this is the crowding problem.

t-SNE's answer: instead of cramming all neighbors into 2D, allow them to be "slightly farther". Use Student-t distribution in low-D — its long tails give medium distances higher probability, giving pushed-away friends a "safe zone".

📌 0-2 Gaussian vs t 分布：尾巴的長短0-2 Gaussian vs t-distribution: tail length

Student-t 分布最關鍵的特點是「長尾」——遠離中心的機率比 Gaussian 高很多。這就是為什麼 t-SNE 能解決擠擁問題： 允許低維中「中等距離」獲得不可忽略的機率，讓被推開的鄰居不會被視為「完全不相關」。

把游標移到曲線上看任意 $r$ 處兩分布的數值差。

Student-t's key property: heavy tails — much higher probability at large distances than Gaussian. This is why t-SNE solves crowding: medium-distance neighbors get non-negligible weight.

📌 0-3 三句話總結：t-SNE 在做什麼0-3 t-SNE in three sentences

  1. 在高維算「鄰居機率 $p_{ij}$」（用 Gaussian 核 + perplexity 控制鄰居數）。
  2. 在低維算「鄰居機率 $q_{ij}$」（用 Student-t 核解決擠擁）。
  3. 用 KL 散度強迫 $q \approx p$，讓低維結構複製高維結構。
  1. High-D probabilities $p_{ij}$ (Gaussian kernel, perplexity-controlled).
  2. Low-D probabilities $q_{ij}$ (Student-t kernel — crowding solved).
  3. Minimize KL divergence to make $q \approx p$.
🔗 跟 UMAP 的對應🔗 Map to UMAP

如果你已經讀過 M3.3 UMAP，這三句話聽起來眼熟——是的，UMAP 的高層架構幾乎相同。差別在： t-SNE 用 KL 散度（只有吸引力），UMAP 用 cross-entropy（吸引 + 排斥）。這個差別讓兩者行為大不同（§9 詳細對比）。

If you've read M3.3 UMAP, the architecture sounds familiar. Key difference: t-SNE uses KL (attractive only); UMAP uses cross-entropy (attractive + repulsive). This produces very different behavior (compared in §9).

§1 · SNE 直覺 / FIRST INTUITION

先理解 SNE：t-SNE 的前身

Understand SNE first: t-SNE's predecessor

SNE (Stochastic Neighbor Embedding) 是 Hinton 在 2002 年提出的方法，t-SNE (2008) 是它的改進版。理解 SNE 才知道 t-SNE 解決了什麼問題。

SNE 的核心想法：把「鄰居」轉成「機率」。對每個高維點 $x_i$，給每個其他點 $x_j$ 一個「是 $i$ 的鄰居」的機率 $p_{j|i}$。 然後在低維把點 $y_i$ 散開，讓低維機率 $q_{j|i}$ 盡量符合高維機率。

為什麼用機率而不直接保留距離？因為機率自然處理了「鄰居關係的不確定性」—— $p_{j|i} = 0.7$ 比「距離 = 1.43」更穩健、更不依賴尺度。

SNE (Stochastic Neighbor Embedding), proposed by Hinton (2002), is t-SNE's predecessor (2008).

SNE's core idea: turn "neighbor" into "probability". Probabilities are scale-robust and naturally handle neighborhood uncertainty.

§2 · 核心數學 / HIGH-D PROBABILITY

高維機率分布 P

High-D probability distribution P

SNE 對每個點 $x_i$ 用高斯核定義「鄰居條件機率」：

SNE defines conditional neighbor probability using a Gaussian kernel:

$$\boxed{\;p_{j|i} = \frac{\exp\left(-\|x_i - x_j\|^2 / 2\sigma_i^2\right)}{\sum_{k \neq i} \exp\left(-\|x_i - x_k\|^2 / 2\sigma_i^2\right)}\;}$$
$\|x_i - x_j\|^2$$x_i$ 到 $x_j$ 的歐式距離平方Squared Euclidean distance
$\sigma_i$$x_i$ 專屬的「鄰居尺度」Per-point bandwidth
分母Denominator所有可能 $k$ 的和，讓 $\sum_j p_{j|i} = 1$Sum over all $k$, ensures $\sum_j p_{j|i} = 1$

幾個重點：

  • $p_{i|i} = 0$（自己不是自己的鄰居）
  • 分母是「歸一化常數」(softmax)——讓 $p$ 變成有效的機率分布
  • $\sigma_i$ 是每個點獨立的——密集區的點 $\sigma$ 小、稀疏區的點 $\sigma$ 大
  • $p_{j|i}$ 越大 → $x_j$ 越像 $x_i$ 的鄰居

Key points: (1) $p_{i|i} = 0$; (2) denominator is softmax normalization; (3) $\sigma_i$ is per-point; (4) larger $p_{j|i}$ means $x_j$ is a "stronger" neighbor of $x_i$.

🔑 跟 UMAP 的 $w_{j|i}$ 有何不同？ 🔑 How does this differ from UMAP's $w_{j|i}$?

UMAP 的 $w_{j|i} = \exp(-\max(0, d - \rho_i)/\sigma_i)$ 多了 $\rho_i$ 局部尺度修正，且沒有 softmax 歸一化。 t-SNE 沒有 $\rho_i$、有 softmax；UMAP 反之。這個差別讓 t-SNE 對局部密度差異更敏感，是兩者性能差異的數學根源之一。

UMAP has $\rho_i$ local-scale subtraction + no softmax. t-SNE has no $\rho_i$ + softmax. This is one root of behavioral differences.

§3 · 關鍵超參數 / PERPLEXITY

Perplexity：「有效鄰居數」

Perplexity: "Effective neighbor count"

$\sigma_i$ 不是隨便給的——它由使用者設定的 perplexity 反推：

$\sigma_i$ is determined by user-set perplexity:

$$\boxed{\;\mathrm{Perp}(P_i) = 2^{H(P_i)}, \quad H(P_i) = -\sum_j p_{j|i} \log_2 p_{j|i}\;}$$
$H(P_i)$分布 $P_i$ 的「Shannon 熵」(對數底為 2 → 單位 bits)Shannon entropy of $P_i$ (base 2)
$2^{H}$「有效鄰居數」——若分布完美均勻於 $k$ 個點，$\mathrm{Perp} = k$"Effective neighbor count"; if uniform over $k$, $\mathrm{Perp}=k$

具體做法：使用者指定 perplexity = 30（典型值），UMAP/t-SNE 對每個 $i$ 二分搜尋 $\sigma_i$，使得 $\mathrm{Perp}(P_i) = 30$。 意思是「對每個點，把它的鄰居強度分散成『相當於 30 個均勻鄰居』」。

為什麼用 $2^H$ 而不直接用 $H$？因為「鄰居數」這個概念對人類更直觀。perplexity = 30 ≈ 「30 個鄰居對我有同等影響」。

User sets perplexity = 30 (typical); binary search $\sigma_i$ so $\mathrm{Perp}(P_i) = 30$ for each $i$. Means: "for each point, neighbor influence is equivalent to 30 uniform neighbors."

§4 · 對稱化 / SYMMETRIZATION

為什麼要對稱化？

Why symmetrize?

$p_{j|i}$ 是條件機率——它不對稱：$p_{j|i} \neq p_{i|j}$（因為 $\sigma_i \neq \sigma_j$）。 但「$i$ 和 $j$ 是不是邊」應該是對稱關係。早期 SNE 用條件機率所以梯度公式很醜，t-SNE 改成聯合機率：

$p_{j|i}$ is asymmetric since $\sigma_i \neq \sigma_j$. Early SNE used conditionals (ugly gradient). t-SNE switched to joint probabilities:

$$\boxed{\;p_{ij} = \frac{p_{j|i} + p_{i|j}}{2n}\;}$$
$+$兩個方向求和，使其對稱Sum both directions for symmetry
$/2n$歸一化使 $\sum_{i,j} p_{ij} = 1$（$n$ 是樣本數）Normalize so $\sum_{i,j} p_{ij} = 1$

注意：t-SNE 的對稱化跟 UMAP 不同：

  • t-SNE：$p_{ij} = (p_{j|i} + p_{i|j}) / 2n$（平均後再歸一化）
  • UMAP：$\mu_{ij} = w_{j|i} + w_{i|j} - w_{j|i} w_{i|j}$（fuzzy union）

兩種都讓結果對稱，但用了不同數學工具：t-SNE 用算術平均、UMAP 用「至少一個方向是鄰居」的容斥原理。

t-SNE: arithmetic mean. UMAP: fuzzy union (inclusion-exclusion). Both yield symmetry via different mechanisms.

⚠️ 一個常見誤解⚠️ Common misconception

很多人以為「對稱化只是技術細節」。其實這是 t-SNE 跟 SNE 的關鍵差別之一，讓梯度公式變得超級簡單（§7 會看到）。 symmetric SNE 仍用 Gaussian 低維核，但梯度形式更乾淨——已經是 t-SNE 的一半了。

Many think symmetrization is just bookkeeping. Actually it's a key t-SNE vs SNE difference, dramatically simplifying gradient (see §7).

§5 · 核心問題 / CROWDING

擠擁問題：為什麼 SNE 不夠用

The Crowding Problem: Why SNE alone fails

假設我們用「Gaussian 在高維、Gaussian 在低維」（這就是對稱 SNE）。為什麼結果不好？ 回到 §0 的舞會：在 $d$ 維空間有「中等距離」的點數量是 $O(d^{d-1})$（球殼體積），但在 2D 只有 $O(1)$。 所以「中等距離鄰居」在低維有系統性的容量不足。

結果：SNE 強迫 $q_{ij}$ 像 $p_{ij}$，於是「中等距離鄰居」的 $q$ 必須跟 $p$ 一樣高—— 但 Gaussian 在中距離衰減太快，做不到。SNE 只能「把所有鄰居都擠到一起」。

Use "Gaussian in high-D, Gaussian in low-D" (= symmetric SNE). Why does it fail?

In $d$ dimensions, the number of "medium-distance" points is $O(d^{d-1})$ (shell volume); in 2D only $O(1)$. Systematic capacity shortage. Gaussian's fast decay can't compensate — SNE crowds everything together.

💡 直覺重點💡 Intuition

在高維「中距離」是常態（最多點落在這裡）；在 2D「中距離」很稀少（被擠到「近」或「遠」兩極化）。 要把高維結構複製到 2D，我們需要讓「中距離」在低維也有不可忽略的機率——這就是 Student-t 進場的地方。

In high-D, medium distance is the norm. In 2D, it's rare. We need a low-D kernel that keeps medium-distance probability non-trivial — Student-t to the rescue.

§6 · 解決方案 / t SAVES THE DAY

Student-t 分布：長尾解決擠擁

Student-t: long tails to the rescue

t-SNE 把低維機率從 Gaussian 換成自由度 1 的 Student-t（也就是 Cauchy 分布）：

t-SNE replaces low-D Gaussian with Student-t (df = 1, equivalent to Cauchy):

$$\boxed{\;q_{ij} = \frac{(1 + \|y_i - y_j\|^2)^{-1}}{\sum_{k \neq l} (1 + \|y_k - y_l\|^2)^{-1}}\;}$$
$(1+r^2)^{-1}$Cauchy 分布核 — 沒有指數衰減Cauchy kernel — no exponential decay
分母Denominator所有點對 $(k,l)$ 的和，歸一化Sum over all pairs $(k,l)$ for normalization

為什麼是「自由度 1」的 t？因為它的尾巴最長（df 越大越接近 Gaussian）。 具體形狀：$q \propto (1+r^2)^{-1}$ — 在 $r$ 大時只衰減為 $1/r^2$，而 Gaussian 是 $e^{-r^2}$ 指數衰減（快很多）。

Why df = 1? It has the heaviest tail (larger df → closer to Gaussian). Decay is $1/r^2$ (polynomial) vs Gaussian's exponential — much slower.

§7 · 目標函數 / KL OBJECTIVE

KL 散度與優雅的梯度

KL Divergence and the Elegant Gradient

t-SNE 要讓 $q$ 盡量接近 $p$，用 KL 散度量化「兩個分布的距離」：

t-SNE minimizes KL divergence between $p$ and $q$:

$$\boxed{\;C = \mathrm{KL}(P \,\|\, Q) = \sum_{i \neq j} p_{ij} \log\frac{p_{ij}}{q_{ij}}\;}$$
$p_{ij}$高維「真實」分布（固定）High-D "ground truth" (fixed)
$q_{ij}$低維「當前」分布（被優化）Low-D current distribution (optimized)
$\log \frac{p}{q}$「資訊差」——$q$ 跟 $p$ 不一致就吃虧Information gap — penalty for mismatch

關鍵性質：KL 散度是非對稱的。$\mathrm{KL}(P \| Q) \neq \mathrm{KL}(Q \| P)$。 t-SNE 選的方向 $P \| Q$ 意思是：「$p_{ij}$ 大但 $q_{ij}$ 小」會受重罰，但「$p_{ij}$ 小但 $q_{ij}$ 大」幾乎不被罰。 結果：t-SNE 強烈傾向保留局部結構（讓真鄰居在低維也是鄰居），但對「不該是鄰居卻在低維變近」沒辦法處理—— 這就是它「全局結構差」的根本原因。

KL is asymmetric. $\mathrm{KL}(P\|Q) \neq \mathrm{KL}(Q\|P)$. The choice $P\|Q$ heavily penalizes large $p$ + small $q$ (missing real neighbors), but barely penalizes small $p$ + large $q$ (false neighbors). Hence t-SNE preserves local structure well but global structure poorly.

梯度：吸引力與排斥力

Gradient: attractive and repulsive forces

$$\frac{\partial C}{\partial y_i} = 4 \sum_{j \neq i} \underbrace{(p_{ij} - q_{ij})}_{\text{誰大?}} \underbrace{(y_i - y_j) (1 + \|y_i - y_j\|^2)^{-1}}_{\text{方向 × 衰減}}$$
梯度只依賴 $p - q$ 差和當前距離 — 數學上「優雅」就是這意思
Gradient depends only on $p - q$ and current distance — mathematically "elegant"
  • 當 $p_{ij} > q_{ij}$（高維是鄰居但低維太遠）→ 力把 $y_i, y_j$ 拉近（吸引）
  • 當 $p_{ij} < q_{ij}$（高維不是鄰居但低維太近）→ 力把 $y_i, y_j$ 推開（排斥）
  • 距離係數 $(1 + r^2)^{-1}$ 讓「遠距離點對」貢獻不會炸開
  • $p > q$ → attractive force
  • $p < q$ → repulsive force
  • $(1+r^2)^{-1}$ factor keeps distant pairs from exploding

§10 · 手算 / WORKED EXAMPLE

親手算一遍：5 個點的 t-SNE

Compute t-SNE by hand: 5 points

5 個 2D 點：$x_1 = (0,0)$、$x_2 = (1,0)$、$x_3 = (3,0)$、$x_4 = (3,1)$、$x_5 = (5,5)$。Perplexity = 2。

5 points; perplexity = 2.

步驟 1：高維距離平方矩陣Step 1: Squared distance matrix 
       x1     x2     x3     x4     x5
x1     0      1      9     10     50
x2     1      0      4      5     41
x3     9      4      0      1     29
x4    10      5      1      0     20
x5    50     41     29     20      0
步驟 2：對每個 $i$ 二分搜尋 $\sigma_i$ 達 perplexity = 2Step 2: Binary search $\sigma_i$
以 $x_1$ 為例，假設 $\sigma_1 = 1.5$ 試試：
For $x_1$, try $\sigma_1 = 1.5$:
        exp(-d²/(2σ²)) = exp(-d²/4.5)
        x2: exp(-1/4.5) = 0.801
        x3: exp(-9/4.5) = 0.135
        x4: exp(-10/4.5) = 0.108
        x5: exp(-50/4.5) ≈ 0.0000139

        分母 sum = 0.801 + 0.135 + 0.108 + 0.0000139 ≈ 1.044

        p_{2|1} = 0.801/1.044 = 0.767
        p_{3|1} = 0.135/1.044 = 0.129
        p_{4|1} = 0.108/1.044 = 0.103
        p_{5|1} = 0.0000133

        H(P_1) = -Σ p log₂ p ≈ 1.12 bits
        Perp(P_1) = 2^1.12 ≈ 2.17  (太接近 2，σ_1 ≈ 1.45 即可)
同理算 $\sigma_2, \ldots, \sigma_5$。實作上是自動二分搜尋（log 範圍）。
步驟 3：對稱化得 $p_{ij}$Step 3: Symmetrize 
p_{12} = (p_{2|1} + p_{1|2}) / (2·5)
       = (0.767 + 0.823) / 10  ≈ 0.159

p_{13} = (0.129 + 0.060) / 10  ≈ 0.019
p_{45} = (0.001 + 0.002) / 10  ≈ 0.0003
... 共 C(5,2) = 10 個非零 p_{ij}
步驟 4：初始化低維 + early exaggerationStep 4: Init + early exaggeration
$y_1 \ldots y_5$ 初始為 $\mathcal{N}(0, 10^{-4})$ 的隨機 2D 點。前 250 個 epochs 把 $p_{ij}$ 乘以 12（「early exaggeration」）， 強迫鄰居拼命靠近，幫助形成「群」結構。
$y_i \sim \mathcal{N}(0, 10^{-4})$. First 250 epochs: multiply $p_{ij}$ by 12 ("early exaggeration") to form clusters.
步驟 5：梯度下降 1000 epochsStep 5: Gradient descent 1000 epochs 
for epoch in 1..1000:
    Q ← compute q_{ij} from current Y
    grad_i = 4 Σ_j (p_{ij} - q_{ij}) (y_i - y_j) (1 + ||y_i - y_j||²)⁻¹
    Y ← Y - lr · grad + momentum · prev_velocity

    if epoch == 250: p ← p / 12  # end early exaggeration

§11 · Wattenberg 的 5 大陷阱 / 5 PITFALLS

Wattenberg 等人 (2016) 的 5 大 t-SNE 陷阱

5 t-SNE pitfalls (Wattenberg et al. 2016)

Distill 的經典文章「How to Use t-SNE Effectively」整理出 5 個最常見的誤詮釋：

The classic Distill article identifies 5 common misinterpretations:

陷阱 1 · PITFALL 1

群之間的距離不重要

Cluster distances are meaningless

看到 t-SNE 圖上 A 群跟 B 群相隔很遠、A 群跟 C 群相鄰，不能得出「A 跟 C 比較像」的結論。 t-SNE 只保留「誰是誰的鄰居」，群間距離是 KL 優化過程的副產物，沒有意義。

Don't conclude "A is more like C than B" from inter-cluster distances. t-SNE preserves only neighborhood, not global distance.

陷阱 2 · PITFALL 2

群的大小不重要

Cluster sizes are meaningless

t-SNE 會把所有群「氣球化」到差不多大。原本資料中很緊密的群可能在 t-SNE 圖上跟很鬆散的群看起來一樣大。

t-SNE balloons all clusters to similar size. Tight high-D clusters appear same size as loose ones.

陷阱 3 · PITFALL 3

隨機 init 讓不同 seed 結果不一樣

Random init: different seeds → different results

梯度下降的隨機初始化讓不同 seed 產生「同樣分群結構但位置不同」的圖。要嚴格比較必須固定 seed。 Kobak & Linderman (2021) 建議用 PCA init 取代隨機，可大幅改善全局結構。

Random gradient descent yields layouts that differ across seeds. Fix seed for comparison. Kobak & Linderman (2021): use PCA init.

陷阱 4 · PITFALL 4

Perplexity 對結果影響極大

Perplexity dramatically affects results

perplexity = 5 跟 perplexity = 50 看起來像兩個完全不同的世界——前者偏局部、後者偏全局。 實務上至少測 3 個值 (5, 30, 50)，看哪個結構穩定。

Perplexity 5 vs 50 yield wildly different views. Try multiple values in practice.

陷阱 5 · PITFALL 5

「看起來有結構」不代表真的有

"Looks like structure" ≠ real structure

t-SNE 對隨機高斯雲（沒有任何結構的資料）有時也會「擠」出看似的小群—— 這只是優化過程的副產物。看 t-SNE 圖前，先檢查資料的 elbow plot / PCA scree， 確認真的有低維結構再用。

t-SNE may "find" clusters in noise. Verify real structure via elbow / PCA scree first.

§12 · 整理 / SUMMARY

把整套故事串起來

The whole story

t-SNE 的 7 個核心思想：

  1. 機率取代距離：對尺度穩健、便於後續優化（§1）
  2. 高維 Gaussian + softmax：定義 $p_{j|i}$，每個點獨立 $\sigma_i$（§2）
  3. Perplexity 控制有效鄰居數：典型 5-50，二分搜尋 $\sigma$（§3）
  4. 對稱化：$p_{ij} = (p_{j|i}+p_{i|j})/2n$，讓梯度公式變優雅（§4）
  5. 擠擁問題：高維中距離鄰居在 2D「容不下」（§5）
  6. Student-t 救援：長尾給中距離安全位置（§6）
  7. KL 散度 + 優雅梯度：吸引/排斥力推動嵌入（§7）

t-SNE's 7 ideas: (1) Probability over distance, (2) Gaussian + softmax in high-D, (3) Perplexity, (4) Symmetrization, (5) Crowding problem, (6) Student-t to the rescue, (7) KL with elegant gradient.
