§0 · 故事開場 / STORY

假設你是一隻爬在地球儀上的螞蟻

Imagine you're an ant crawling on a globe

你住在「地球表面」上。對你來說，「距離」是沿著彎曲表面走的距離——不是穿過地心的直線。 如果有人告訴你「台北到紐約距離 12,000 公里」，那是表面距離，不是歐式直線距離（穿地心約 11,000 公里）。

這就是流形 (manifold) 假設的核心：高維空間裡的資料其實住在一個彎曲的低維表面上。 要正確「描述距離」，你不能只看 3D 空間的歐式距離——你要看「在流形上走的距離」。 但流形我們看不到，只看得到資料點散在 3D 空間。怎麼辦？

UMAP 的回答：別管全局距離了。只要保留誰是誰的「鄰居」，就能還原流形結構。 接下來我們會看到，這個簡單想法的數學形式如何讓 UMAP 在 scRNA-seq 變成標準。

You live on Earth's surface. For you, "distance" means traveling along the curved surface — not through Earth's core. Taipei → New York is 12,000 km on the surface (not the 11,000 km straight through).

This is the manifold hypothesis: high-D data live on a curved low-D surface. You can't see the manifold directly — only the points scattered in 3D. So how do you recover its structure?

UMAP's answer: forget global distance. Just preserve who is whose neighbor, and the manifold structure emerges.

📌 0-3 三句話總結：UMAP 在做什麼0-3 UMAP in three sentences

  1. 看高維空間裡誰是誰的鄰居 → 算出「高維鄰居機率 $\mu_{ij}$」。
  2. 把點隨機撒到低維 → 算「低維鄰居機率 $\nu_{ij}$」。
  3. 用 cross-entropy 強迫 $\nu \approx \mu$，讓低維結構複製高維結構。
  1. Compute high-D neighbor probabilities $\mu_{ij}$.
  2. Randomly initialize low-D points → compute $\nu_{ij}$.
  3. Use cross-entropy to push $\nu \approx \mu$, copying high-D structure to low-D.

本頁接下來會把每一句的數學細節攤開。你看完最後一節時，會發現 UMAP 真的只是這三句話。

This page unfolds the math behind each sentence. By the end, UMAP is exactly these three sentences.

§1 · 第一個直覺 / FIRST INTUITION

為什麼是「保留鄰居」而不是「保留距離」？

Why preserve neighbors, not distances?

PCA 試圖保留資料的變異量——但這假設資料是「線性」的。如果資料住在彎曲流形上，PCA 的「直線方向」就抓不到重點。

另一個自然想法：保留所有點對距離（這就是 MDS、Isomap）。但這需要 $O(n^2)$ 個距離全部對得上，計算量大且容易過度擬合。

UMAP 採用一個更聰明的折衷：只保留「誰是誰的近鄰」的拓撲關係。 具體說，對每個點 $i$，只在意「跟我最近的 $k$ 個點是誰」（$k \approx 15$ 是常用值）。 遠距離資訊全部丟掉——這就是為什麼 UMAP 不保留全局距離。

PCA preserves variance, but assumes linearity. MDS/Isomap preserve all pairwise distances, but that's $O(n^2)$ and overfits. UMAP's compromise: preserve only "who is whose neighbor" topology — for each $i$, only the closest $k$ matter ($k \approx 15$). All long-range info is discarded.

§2 · 核心數學 / HIGH-D PROBABILITY

把「鄰居關係」變成機率

Turning "neighborhood" into probability

對每個點 $i$，UMAP 用高斯核計算「$j$ 是 $i$ 的鄰居」的條件機率：

For each point $i$, UMAP uses a Gaussian-like kernel to compute the probability "$j$ is a neighbor of $i$":

$$\boxed{\; w_{j|i} = \exp\left( -\frac{\max(0,\; d(x_i, x_j) - \rho_i)}{\sigma_i} \right) \;}$$
$d(x_i, x_j)$$x_i$ 到 $x_j$ 的歐式距離Euclidean distance from $x_i$ to $x_j$
$\rho_i$$x_i$ 到「最近鄰」的距離（§3 詳解）Distance from $x_i$ to its 1st neighbor (see §3)
$\sigma_i$$x_i$ 專屬的「尺度」參數，下面討論Per-point bandwidth, see below
$\max(0,\cdot)$確保最近的點都拿到「滿分 1」，再遠才衰減Ensures nearest points get full weight 1; only farther ones decay

$\sigma_i$ 怎麼定？UMAP 要求每個點的「期望鄰居數」相同。具體說，要求：

How is $\sigma_i$ chosen? UMAP requires each point's "effective neighbor count" to be equal:

$$\sum_j w_{j|i} = \log_2(k)$$
$k$ 是使用者設的「目標鄰居數」(n_neighbors)。$\log_2$ 是經驗選擇，讓「有效鄰居數」隨 $k$ 對數增長。
$k$ is user-set (n_neighbors). $\log_2$ is empirical, giving logarithmic growth.

用二分搜尋找滿足這條件的 $\sigma_i$。關鍵效果：密集區域的點 $\sigma_i$ 小（鄰居們都近）、稀疏區域的點 $\sigma_i$ 大（鄰居們較遠）。 UMAP 自動適應局部密度。

Found via binary search. Dense regions get small $\sigma_i$; sparse regions get large $\sigma_i$. Automatic density adaptation.

§3 · 核心巧思 / LOCAL SCALE

$\rho_i$：UMAP 最關鍵的一行公式

$\rho_i$: UMAP's most important line

還記得公式 $w_{j|i} = \exp\left(-\frac{\max(0, d - \rho_i)}{\sigma_i}\right)$ 中那個 $\rho_i$？它定義為：

Recall the kernel. The $\rho_i$ is defined as:

$$\rho_i = \min_{j \in \mathcal{N}_k(i),\, j \neq i} d(x_i, x_j)$$
$\rho_i$ = $x_i$ 到「最近 (非自身) 鄰居」的距離
$\rho_i$ = distance from $x_i$ to its closest non-self neighbor

看起來不起眼，但這是 UMAP 與其他方法分道揚鑣的地方。為什麼要減 $\rho_i$？因為流形假設說「局部均勻」—— 也就是說，每個點周圍最近的那個鄰居「應該」是等距的。所以我們把它的距離當作「局部尺度標準」，把它正規化掉。

結果：每個點到自己最近鄰的距離都會被當成「0」，後續距離才衰減。 這讓不同密度區域的點都被「對齊」到同樣的尺度。

Innocent-looking but pivotal. By the manifold hypothesis, nearest neighbors should be equidistant locally. So $\rho_i$ is the local scale to subtract. Effect: every point's nearest neighbor distance becomes "0"; decay starts from there. Dense and sparse regions get rescaled to a common scale.

🔑 關鍵連結 🔑 Key insight

如果沒有 $\rho_i$，UMAP 等於對所有點用同一個高斯核——本質上會像 t-SNE 一樣偏向「擠群」。 $\rho_i$ + 不同 $\sigma_i$ 構成 UMAP 的「自適應局部度量」，是它保留全局結構的數學基礎。

Without $\rho_i$, UMAP would behave like t-SNE (crowd-prone). $\rho_i$ + per-point $\sigma_i$ gives UMAP its "adaptive local metric" — the foundation for preserving global structure.

§4 · 對稱化 / SYMMETRIZATION

為什麼需要對稱化？

Why symmetrize?

$w_{j|i}$ 是「從 $i$ 看出去」的條件機率——它不對稱：$w_{j|i} \neq w_{i|j}$。 但我們在乎的是「$i$ 和 $j$ 是否互為鄰居」這個對稱關係，所以需要把兩個方向合起來。

UMAP 用「模糊聯集 (fuzzy union)」對稱化：

$w_{j|i}$ is asymmetric. We need symmetric "is $(i,j)$ an edge?", so we combine both directions with fuzzy union:

$$\boxed{\;\mu_{ij} = w_{j|i} + w_{i|j} - w_{j|i} \cdot w_{i|j}\;}$$
$\mu_{ij}$高維「邊機率」，$\in [0, 1]$High-D edge probability
$+$兩個方向「都算數」Both directions count
$- w_{j|i} w_{i|j}$避免雙重計算（容斥原理）Inclusion-exclusion: avoid double-counting

為什麼這個式子？想像兩個獨立事件 $A, B$，它們至少有一個發生的機率是 $P(A) + P(B) - P(A \cap B)$。 把「$j$ 是 $i$ 的鄰居」和「$i$ 是 $j$ 的鄰居」當成兩個獨立事件，就是這個式子。「模糊」在於這些「事件」是連續值 (0~1)，而非二元真假。

術語：把 $\mu_{ij}$ 視為「邊 $(i,j)$ 屬於『流形圖』的模糊隸屬度」。 這就是 fuzzy simplicial set 這個嚇人名詞背後的東西——它只是「機率加權的圖」而已。

It's just inclusion-exclusion for "at least one direction is a neighbor". The "fuzzy" part: events are continuous (0-1) not binary.

Terminology: $\mu_{ij}$ is the fuzzy membership of edge $(i,j)$ in the manifold graph. That's all "fuzzy simplicial set" means — a probability-weighted graph.

§5 · 低維嵌入 / LOW-D KERNEL

低維空間用什麼核？

Which kernel for the low-D space?

把點散到 2D 後（$y_i \in \mathbb{R}^2$），同樣需要計算「低維鄰居機率 $\nu_{ij}$」。UMAP 用「類 Student-t 核」：

For 2D embeddings $y_i$, we similarly need $\nu_{ij}$. UMAP uses a Student-t-like kernel:

$$\boxed{\;\nu_{ij} = \left( 1 + a \,\|y_i - y_j\|^{2b}\right)^{-1}\;}$$
$a, b$兩個形狀參數，由 min_dist、spread 擬合決定（典型 $a \approx 1.58, b \approx 0.9$）Shape params from min_dist, spread (typical $a \approx 1.58, b \approx 0.9$)

跟 t-SNE 的 Cauchy 核 $(1+r^2)^{-1}$ 很像，但多了 $a, b$ 兩個調整旋鈕。 min_dist 控制「最小允許距離」——小 → 群內擠很緊、大 → 群內鬆散； spread 控制「整體展開程度」。

Similar to t-SNE's Cauchy $(1+r^2)^{-1}$ but with knobs. min_dist = how tight clusters pack; spread = global scale.

§6 · 目標函數 / OBJECTIVE

Cross-Entropy：兩股力量在拉扯

Cross-Entropy: a tug-of-war

UMAP 要讓低維機率 $\nu$ 盡量接近高維機率 $\mu$。用 cross-entropy 量化「兩個 Bernoulli 分布的距離」：

UMAP minimizes the cross-entropy between two Bernoulli distributions $\mu$ and $\nu$:

$$\boxed{\;\mathrm{CE}(\mu, \nu) = \sum_{i \neq j} \underbrace{\mu_{ij} \log\frac{\mu_{ij}}{\nu_{ij}}}_{\text{吸引力 attraction}} + \underbrace{(1 - \mu_{ij}) \log\frac{1 - \mu_{ij}}{1 - \nu_{ij}}}_{\text{排斥力 repulsion}}\;$$
第一項Term 1「高維是鄰居」($\mu$ 大) 但低維不像 ($\nu$ 小) → 拉近Neighbors in high-D ($\mu$ large) but not low-D → pull together
第二項Term 2「高維不是鄰居」($\mu$ 小) 但低維太近 ($\nu$ 大) → 推開Not neighbors in high-D but too close in low-D → push apart

關鍵對比：t-SNE 只用第一項 (KL 散度)——缺乏排斥項是 t-SNE 全局結構差的原因。 UMAP 加上排斥項讓「不該是鄰居的點」主動拉開，分群之間的距離才有意義。

實際優化用 SGD + 負取樣：每次只算「一個真實鄰居（吸引）」+「5 個隨機點（排斥）」， 避免 $O(n^2)$ 計算。這就是 UMAP 比 t-SNE 快 3-10 倍的原因。

Contrast: t-SNE uses only Term 1 (KL); the missing repulsion term is why t-SNE's global structure is poor. Optimized via SGD + negative sampling: 1 true neighbor + 5 random points per step, avoiding $O(n^2)$.

§9 · 手算範例 / WORKED EXAMPLE

親手算一遍：5 個點的 UMAP

Compute UMAP by hand: 5 points

5 個 2D 點：$x_1 = (0,0)$、$x_2 = (1, 0.2)$、$x_3 = (3, 0)$、$x_4 = (3.2, 1)$、$x_5 = (5, 5)$。 $k = 2$（每個點看最近 2 個鄰居）。

5 points; $k=2$.

步驟 1：距離矩陣Step 1: Distance matrix 
       x1     x2     x3     x4     x5
x1   0.000  1.020  3.000  3.354  7.071
x2   1.020  0.000  2.012  2.391  6.131
x3   3.000  2.012  0.000  1.020  5.385
x4   3.354  2.391  1.020  0.000  4.408
x5   7.071  6.131  5.385  4.408  0.000
步驟 2：找 $\rho_i$（每個點到最近鄰的距離）Step 2: $\rho_i$ 
ρ_1 = min(1.020, 3.000, ...) = 1.020   (最近是 x2)
ρ_2 = min(1.020, 2.012, ...) = 1.020   (最近是 x1)
ρ_3 = min(2.012, 1.020, ...) = 1.020   (最近是 x4)
ρ_4 = min(2.391, 1.020, ...) = 1.020   (最近是 x3)
ρ_5 = min(7.071, 6.131, 5.385, 4.408) = 4.408   (最近是 x4)
步驟 3：用二分搜尋找 $\sigma_i$ 滿足 $\sum_j w_{j|i} = \log_2(2) = 1$Step 3: Find $\sigma_i$ s.t. $\sum w = \log_2(2) = 1$
以 $x_1$ 為例。距離 ($d - \rho$) 為：[0, 0, 1.98, 2.33, 6.05]（$d - \rho$ 後 $\max(0, \cdot)$）。 想要 $\sum_j \exp(-d'_j/\sigma_1) = 1$。手算迭代：
For $x_1$: residual distances $[0, 0, 1.98, 2.33, 6.05]$ (post $\max(0, d-\rho)$). Want $\sum \exp(-d'/\sigma) = 1$.
σ = 1.0 → exp[0,0,-1.98,-2.33,-6.05] sum ≈ 1+1+0.138+0.097+0.002 = 2.24  (太大)
σ = 0.5 → exp[0,0,-3.96,-4.66,-12.1] sum ≈ 1+1+0.019+0.009+0 = 2.03  (還是太大)
... 二分搜尋至 σ_1 ≈ 0.40 → sum ≈ 2.00（注意 i=j 時 d=0 也算 → 通常排除自身）
正規化排除自身後：σ_1 ≈ 1.45 滿足 sum_{j≠1} w = 1
同理算 $\sigma_2, \sigma_3, \sigma_4, \sigma_5$。實作上是自動二分搜尋，不用手算。
步驟 4：算 $w_{j|i}$、對稱化得 $\mu_{ij}$Step 4: Compute $w_{j|i}$, symmetrize
假設算出 $w_{2|1} = 1.00$、$w_{1|2} = 1.00$、$w_{3|1} = 0.25$、$w_{1|3} = 0.18$。對稱化：
μ_{1,2} = 1.00 + 1.00 - 1.00·1.00 = 1.00   (互為最近鄰，強連結)
μ_{1,3} = 0.25 + 0.18 - 0.25·0.18 = 0.385  (中等)
μ_{1,5} ≈ 0.001 (幾乎不連結)
最終得到一個 5×5 的邊機率矩陣 $\boldsymbol\mu$，這就是 fuzzy simplicial set 的具體形式。
步驟 5：初始化 $y_i$ + SGD 迭代（500-1000 步）Step 5: Init + SGD
隨機 (或 spectral) 初始化 $y_1, \ldots, y_5 \in \mathbb{R}^2$。每步：
  1. 抽一條真實邊 $(i, j)$（按 $\mu_{ij}$ 加權抽）→ 計算 $\partial \mathrm{CE}/\partial y_i$ 拉近 $y_i, y_j$
  2. 隨機抽 5 個負例 $k$ → 推開 $y_i, y_k$
  3. 更新位置，學習率隨步數線性衰減

Init randomly or spectrally. Each step: sample edge (attract); sample 5 negatives (repel); update with decaying LR.

🎯 觀察🎯 Observe

手算只是讓你看「演算法的每一步在做什麼」。實務上 numpy + scikit-learn 的 UMAP 是 C++ 實作，秒殺 100 萬點。 但理解這 5 步之後，你看 source code 就不會被嚇到。

Hand calculation reveals what each step does. Production UMAP is C++; understanding these 5 steps makes the source readable.

§11 · 整理 / SUMMARY

把整套故事串起來

The whole story

UMAP 的 7 個核心思想：

  1. 流形假設：高維資料住在低維彎曲表面上（§0）
  2. 只保留鄰居拓撲，不保留全局距離（§1）
  3. 鄰居機率用高斯核計算，$\sigma_i$ 自適應（§2）
  4. $\rho_i$ 局部尺度修正讓不同密度區域可比（§3）
  5. 對稱化用 fuzzy union 把方向合併（§4）
  6. 低維 t 核讓「中等距離」獲得強斥力（§5）
  7. Cross-Entropy 用吸引 + 排斥兩力推動 SGD（§6）

UMAP's 7 ideas: (1) Manifold hypothesis (§0), (2) Preserve neighbor topology not global distance (§1), (3) Gaussian kernel with adaptive $\sigma_i$ (§2), (4) $\rho_i$ local scale (§3), (5) Fuzzy union symmetrization (§4), (6) Low-D t-kernel for repulsion (§5), (7) Cross-entropy with SGD + negative sampling (§6).
