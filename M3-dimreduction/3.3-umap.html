UMAP：兼顧 local + global 的非線性降維

UMAP: nonlinear dim reduction preserving local + global

t-SNE 保留局部鄰居關係，但 cluster 間距離不可信。 UMAP（McInnes et al. 2018）改進兩件事： (1) 建一個 fuzzy weighted graph當高維結構描述； (2) 在低維 force-directed 嵌入那個 graph，同時保 local + global。 結果：cluster 內結構好、cluster 間距離也比 t-SNE 可信。

本節從 fuzzy simplicial set 的直覺出發，理解 UMAP 怎麼用 cross-entropy loss + 隨機 negative sampling 跑得比 t-SNE 快 10 倍。
t-SNE preserves local neighbors but inter-cluster distance is unreliable. UMAP (McInnes et al. 2018) improves two things: (1) build a fuzzy weighted graph as the high-D description; (2) force-directed embed that graph in low-D, preserving both local + global. Result: clean cluster structure + reliable inter-cluster distance.

Starting from fuzzy simplicial set intuition, we explain UMAP's cross-entropy loss + random negative sampling that makes it 10× faster than t-SNE.

🧬 scRNA-seq 視角：UMAP 是 scRNA atlas 時代的 Google Maps 🧬 scRNA-seq perspective: UMAP is the Google Maps of the scRNA atlas era

想像 2008 年你要找一間咖啡廳，你會打開紙地圖，慢慢翻、緩緩找——這就是 t-SNE 的時代。但到了 2024 年，你打開 Google Maps，10 秒鐘看完全城、可以放大查街景、還可以把「新地址 query 進去」就立刻知道在哪——這就是 UMAP 帶來的革命。t-SNE 是紙本旅遊地圖（漂亮但慢、不能 query 新地點、cluster 間距離隨便畫），UMAP 是 Google Maps（快、可 query、保 global structure）。 In 2008, finding a café meant unfolding a paper map, scanning slowly — that was the t-SNE era. By 2024, you open Google Maps, see the whole city in 10 seconds, zoom into Street View, and query new addresses instantly — that's the UMAP revolution. t-SNE is a printed travel map (pretty but slow, can't query new spots, inter-cluster distance arbitrary); UMAP is Google Maps (fast, queryable, preserves global structure).

UMAP 是怎麼做到的？它不只記住每個細胞跟誰是鄰居（這部分跟 t-SNE 一樣），還用「fuzzy 連接強度」 量化「誰跟誰多近」——所以 cluster 間距離可信、可保留分化路徑。最厲害的是它有transform 函數：你訓練好一份 reference atlas（例如 HCA），新病人的 cell 進來，一秒投到地圖上找最近鄰標細胞型——這就是 CellTypist、Azimuth 等 reference mapping 工具的底層魔法。所以為什麼 CELLxGENE 50M cells、HCA 全身 atlas 全部用 UMAP？因為只有它跑得動、可 query、可比較。 How does UMAP pull this off? It doesn't just remember who's whose neighbor (so does t-SNE) — it uses a "fuzzy connection strength" to quantify "how close are they", so inter-cluster distances become trustworthy and differentiation paths get preserved. The killer feature: a transform function. Train on a reference atlas (e.g. HCA), and a new patient's cells get projected onto the map in seconds, labeled by nearest neighbors — this is the magic underneath CellTypist, Azimuth, and every reference-mapping tool. Why do CELLxGENE 50M cells, HCA whole-body atlas all run UMAP? Because only UMAP scales, queries, and compares.

§0 故事：t-SNE 解決一半問題Story: t-SNE only solves half

t-SNE 把局部結構保留得很好——「鄰居還是鄰居」。但cluster 之間的距離跟形狀就不可靠： 兩 cluster 在 t-SNE 中相距 10、另兩 cluster 相距 50，兩件事在生物上的意義可能完全一樣。 你也無法把「新細胞」query 進已有的 t-SNE plot（沒 transform 函數）。

t-SNE preserves local structure well — "neighbors stay neighbors". But inter-cluster distance and shape are unreliable: "10 apart" vs "50 apart" in t-SNE may carry identical biological meaning. Also no way to query new cells into an existing t-SNE plot (no transform function).

§0-1 t-SNE vs UMAP：同一資料

§0-1 t-SNE vs UMAP: same data

UMAP 的兩個改進UMAP's two improvements: (1) 在 cross-entropy loss 中用 negative sampling（隨機抽不相關的對推開），不必算所有 n² 對 → 速度 $O(n)$ 訓練； (2) 高維結構用「fuzzy simplicial set」topological description，保留連通性 → cluster 間距離也有意義。 (1) Use negative sampling (random distant pairs push) in cross-entropy loss — no n² needed → $O(n)$ training; (2) High-D structure as "fuzzy simplicial set" topological description — preserves connectivity → inter-cluster distance meaningful.

§1 fuzzy simplicial set 的直覺fuzzy simplicial set intuition

「fuzzy simplicial set」聽起來嚇人，但直覺很簡單：對每個 cell $i$，畫一個軟邊界球， 球內所有點都「有點是鄰居」，距離越近隸屬度越高。 把所有 cell 的軟球疊起來，得到一個加權圖——這就是 UMAP 高維結構描述。

"Fuzzy simplicial set" sounds scary, intuition is simple: for each cell $i$, draw a soft-boundary ball, every point inside is "somewhat a neighbor", closer = higher membership. Overlap all balls → a weighted graph — UMAP's high-D description.

§2 高維 graph 構造High-D graph construction

2.1 局部 metric：$\rho_i$ 跟 $\sigma_i$

2.1 Local metric: $\rho_i$ and $\sigma_i$

$$\rho_i = \min_j \|x_i - x_j\|, \quad \text{(到最近鄰的距離)}$$ $$\sum_j \exp\!\left(-\frac{\max(0, d(x_i, x_j) - \rho_i)}{\sigma_i}\right) = \log_2 k$$
$\rho_i$ = 最近鄰距離；$\sigma_i$ 自動解使「有效鄰居數」= n_neighbors $k$
$\rho_i$ = nearest neighbor distance; $\sigma_i$ solved so "effective neighbors" = $k$

與 t-SNE 不同：UMAP 把最近鄰距離當原點（$\rho_i$），確保每點至少有一個權重 = 1 的邊。保證圖連通。

Unlike t-SNE: UMAP uses nearest-neighbor distance as origin ($\rho_i$), ensuring every point has at least one weight-1 edge. Guarantees connectivity.

2.2 邊權重 (membership strength)

2.2 Edge weight (membership strength)

$$w_{i \to j} = \exp\!\left(-\frac{\max(0, d(x_i, x_j) - \rho_i)}{\sigma_i}\right)$$
從 $i$ 看 $j$ 是「鄰居」的隸屬度 (0~1)
how much $j$ "belongs" to $i$'s neighborhood (0~1)

2.3 對稱化 (probabilistic t-conorm)

2.3 Symmetrize (probabilistic t-conorm)

$$w_{ij} = w_{i \to j} + w_{j \to i} - w_{i \to j} \cdot w_{j \to i}$$
「兩邊任一覺得是鄰居」的隸屬度合併
"either side thinks it's a neighbor" membership

這個 union 公式來自 fuzzy logic（不是 t-SNE 的單純平均），保留非線性 OR 結構。

This union formula comes from fuzzy logic (not t-SNE's simple averaging), preserves nonlinear OR structure.

§4 低維 force-directed embeddingLow-D force-directed embedding

UMAP 把 fuzzy graph $w_{ij}$ 嵌入到 2D，找一組座標 $y_1, \ldots, y_n$ 讓低維「同樣」的邊權跟 $w_{ij}$ 匹配。 低維邊權用一個類似 Student-t 但可調參的 family：

UMAP embeds the fuzzy graph $w_{ij}$ into 2D, finding coordinates so low-D edge weights match $w_{ij}$. Low-D edge weights use a Student-t-like but tunable family:

$$\Phi(y_i, y_j) = \frac{1}{1 + a \cdot \|y_i - y_j\|^{2b}}$$
$a, b$ 由 min_dist 跟 spread 兩個超參數決定（預設 a≈1.93, b≈0.79）
$a, b$ derived from min_dist and spread (defaults a≈1.93, b≈0.79)

4.1 為什麼是這個形式?

4.1 Why this form?

這是 t-SNE Student-t 的「廣義版」——多了參數 $a, b$ 控制「在多近距離開始衰減」（由 min_dist 設定）。 若 min_dist 小 → 同 cluster 點可以擠很近；大 → 強制散開（讓 plot 看起來像 PCA）。

Generalization of t-SNE's Student-t — parameters $a, b$ control "at what distance to start decay" (set by min_dist). Small min_dist → points within cluster can pack tight; large → forced spread (more PCA-like layout).

§5 Cross entropy loss + negative samplingCross entropy + negative sampling

5.1 Binary cross-entropy

5.1 Binary cross-entropy

$$\mathcal{L} = \sum_{i,j} \left[ w_{ij} \log \frac{w_{ij}}{\Phi_{ij}} + (1-w_{ij}) \log \frac{1-w_{ij}}{1-\Phi_{ij}} \right]$$

與 t-SNE 不同：UMAP 的 loss 對「應該不相鄰但低維變近」（第二項）也有強懲罰。這就是 UMAP 能保留 global 結構的關鍵——它真的在乎「不是鄰居的不要靠近」。

Unlike t-SNE: UMAP's loss heavily penalizes "shouldn't be neighbors but became close in low-D" (second term). This is why UMAP preserves global structure — it cares about "non-neighbors stay apart".

5.2 Negative sampling 加速

5.2 Negative sampling for speed

原始公式要對所有 $n^2$ 對算 loss。UMAP 取巧：

Original requires computing loss over $n^2$ pairs. UMAP's trick:

  1. 對每個「正樣本邊」$(i, j)$（$w_{ij} > 0$）→ 拉它們近 For each "positive edge" $(i, j)$ with $w_{ij} > 0$ → pull close
  2. 隨機抽 $m$ 個「負樣本」$(i, k)$（沒邊或不相干）→ 推它們開 Sample $m$ random "negatives" $(i, k)$ → push apart
  3. 用 SGD 更新 $y_i$ SGD update $y_i$
關鍵效能Key efficiency: 每次迭代成本 $O(\text{edges} + n \cdot m)$，總體 $O(n)$（typically m=5）。對 100k cells UMAP 比 t-SNE 快 20-50 倍。 Per-iter cost $O(\text{edges} + n \cdot m)$, total $O(n)$ (typically m=5). For 100k cells, UMAP is 20–50× faster than t-SNE.

§9 PBMC 3k UMAP 完整案例：細胞型態註解的標準流程PBMC 3k UMAP full case: standard cell-type annotation workflow

本節用 PBMC 3k 走 UMAP 完整流程：QC → normalize → HVG → scale → PCA → KNN → UMAP → Leiden → marker annotation。 最終 UMAP 上每個 cluster 標上正確 cell type，這是 scRNA-seq 教學的「金標準」終點。

Walk PBMC 3k full UMAP flow: QC → normalize → HVG → scale → PCA → KNN → UMAP → Leiden → marker annotation. Final UMAP labels each cluster with correct cell type — the "gold standard" endpoint of scRNA tutorials.

9.1 完整 scanpy code

9.1 Full scanpy code

import scanpy as sc

adata = sc.datasets.pbmc3k()

# 1. QC
adata.var["mt"] = adata.var_names.str.startswith("MT-")
sc.pp.calculate_qc_metrics(adata, qc_vars=["mt"], inplace=True)
adata = adata[(adata.obs["n_genes_by_counts"] > 200) &
              (adata.obs["pct_counts_mt"] < 5)].copy()
# 2,638 cells

# 2. Normalize
sc.pp.normalize_total(adata, target_sum=1e4)
sc.pp.log1p(adata)

# 3. HVG
sc.pp.highly_variable_genes(adata, n_top_genes=2000, flavor="seurat_v3")
adata = adata[:, adata.var["highly_variable"]].copy()

# 4. Scale + PCA
sc.pp.scale(adata, max_value=10)
sc.tl.pca(adata, n_comps=50)

# 5. KNN + UMAP
sc.pp.neighbors(adata, n_neighbors=15, n_pcs=30)
sc.tl.umap(adata, min_dist=0.3, spread=1.0)

# 6. Cluster
sc.tl.leiden(adata, resolution=0.5)

# 7. Find markers
sc.tl.rank_genes_groups(adata, "leiden", method="wilcoxon")

# 8. Annotate
new_cluster_names = {
    "0": "CD4 T (naive)",
    "1": "CD14+ Mono",
    "2": "CD4 T (memory)",
    "3": "B cell",
    "4": "CD8 T",
    "5": "NK cell",
    "6": "FCGR3A+ Mono",
    "7": "DC",
    "8": "Megakaryocyte"
}
adata.rename_categories("leiden", new_cluster_names.values())
sc.pl.umap(adata, color="leiden", legend_loc="on data")

§10 深入：Spectral initialization 為何讓 UMAP 全域結構更穩Deep dive: why spectral initialization makes UMAP global structure stable

UMAP 預設用 spectral initialization（從 graph Laplacian 算特徵向量）當 2D 起始位置。 這不是隨機 init！它已經把全域結構放好，所以 SGD 只需要局部微調。Kobak & Linderman (2021) 證明：spectral init 是 UMAP「比 t-SNE 保 global 結構好」的關鍵。

UMAP defaults to spectral initialization (eigenvectors of graph Laplacian) for 2D starting positions. Not random! It pre-places global structure; SGD only fine-tunes locally. Kobak & Linderman (2021) proved: spectral init is the key reason UMAP preserves global structure better than t-SNE.

10.1 數學

10.1 Math

給定 fuzzy graph 的邊權重矩陣 $W$，定義 graph Laplacian:

Given fuzzy graph edge weight matrix $W$, define graph Laplacian:

$$L = D - W, \quad D = \text{diag}(\sum_j W_{ij})$$ $$\text{spectral init} = (\phi_2, \phi_3) \text{ where } L \phi_k = \lambda_k \phi_k$$
取 second + third 個最小特徵向量（first 是 trivial）當 2D 座標
Take 2nd + 3rd smallest eigenvectors (1st is trivial) as 2D coords

10.2 為何 spectral init 保 global 結構

10.2 Why spectral init preserves global

graph Laplacian 的特徵向量是「圖上最 smooth 的非平凡函數」——這些函數的「頻率最低」，自然反映圖的大尺度結構（cluster 間關係）。SGD 在這個基礎上只調 local 微調，不破壞 global。

Laplacian eigenvectors are "smoothest non-trivial functions on the graph" — lowest frequency functions naturally reflect graph's macro structure (inter-cluster relations). SGD only refines locally, preserving global.

對比：random init 為何不好 Contrast: why random init fails 隨機 init 等於「forget 所有 global 結構」，SGD 必須從零開始建。SGD 有 local 視野（只看 negative samples）→ 很容易陷在 local minimum 而 global 結構錯亂。Kobak & Linderman 實測：random init UMAP 結果 ≈ t-SNE（global 隨機）！ Random init = "forget all global". SGD must rebuild from scratch. SGD has local view (only negative samples) → easily stuck in local min, global garbled. Empirically: UMAP with random init ≈ t-SNE (global randomized)!

§11 深入：UMAP 的 Riemannian manifold 理論基礎Deep dive: UMAP's Riemannian manifold foundation

UMAP 名字「Manifold Approximation」不是裝飾——它建立在嚴肅的微分幾何上。 本節揭密「Riemannian metric」「Uniform manifold assumption」這些術語對 scRNA 的意義。

UMAP's name "Manifold Approximation" isn't decoration — it rests on serious differential geometry. We open "Riemannian metric" and "Uniform manifold assumption" jargon for scRNA.

11.1 三個關鍵假設

11.1 Three key assumptions

假設Assumption scRNA 意義scRNA meaning
1. 資料分布在一個 Riemannian manifold 上 1. Data lies on a Riemannian manifold 細胞表現量受連續生物過程限制（lineage, cell cycle）→ 是流形不是隨機點 Cell expression constrained by continuous biology (lineage, cell cycle) → manifold not random points
2. manifold 上 metric 是局部均勻 2. Manifold metric is locally uniform 每細胞周圍密度差很大（dense cluster vs sparse periphery）→ 需要 per-cell σ 校正密度 Density varies (dense clusters vs sparse periphery) → per-cell σ corrects density
3. manifold 是 locally connected 3. Manifold is locally connected 每細胞至少有一個鄰居 → 用 ρ_i 確保 graph 連通 Each cell has ≥1 neighbor → ρ_i ensures graph connectivity

11.2 「Uniform manifold」的數學

11.2 Math of "uniform manifold"

假設真實 manifold 上 metric 均勻（每處密度一樣）。但在歐式空間中觀察到的密度不均勻——所以對每細胞「調整局部 metric」讓它在 manifold 上看起來均勻。這就是 $\rho_i$ + $\sigma_i$ 的數學原因。

Assume metric is uniform on true manifold. But observed density in Euclidean space is non-uniform — so "adjust local metric per cell" to make manifold appear uniform. This is the math reason for $\rho_i$ + $\sigma_i$.

為何這套對 scRNA 特別有效 Why this is especially effective for scRNA: scRNA 的密度極不均勻（PBMC 主要 cell types 各幾百 cells、pDC 只有 30 cells）。Riemannian 校正讓 rare cluster 不被 dense cluster 「淹沒」，保住 rare cell types 的視覺可見性。這也是 UMAP 對 atlas-scale data（500k+ cells）特別好的原因。 scRNA density is extremely non-uniform (PBMC main types have hundreds of cells; pDC has only 30). Riemannian correction prevents rare clusters from being "drowned" by dense ones, keeping rare types visible. This is why UMAP excels on atlas-scale data (500k+ cells).

§12 Supervised UMAP：用 label 引導 embeddingSupervised UMAP: label-guided embedding

UMAP 預設 unsupervised（無視 label）。但如果你已知每細胞的 cell type，可以餵進 UMAP 當 supervision， 讓 embedding 更乾淨地分開 cell types。這是 supervised UMAP（McInnes 2018 §6）。

UMAP defaults to unsupervised (ignores labels). But if you know each cell's type, feed it as supervision — embedding separates types more cleanly. This is supervised UMAP (McInnes 2018 §6).

12.1 數學：加 supervised loss

12.1 Math: add supervised loss

$$\mathcal{L} = (1 - \alpha) \cdot \mathcal{L}_{\text{UMAP}} + \alpha \cdot \mathcal{L}_{\text{supervised}}$$
$\mathcal{L}_{\text{supervised}}$ 用 label 構造額外 attractive/repulsive 邊；$\alpha \in [0,1]$ 控制權重
$\mathcal{L}_{\text{supervised}}$ adds label-driven attractive/repulsive edges; $\alpha \in [0,1]$ controls weight
from umap import UMAP

# Unsupervised (預設)
umap_unsup = UMAP().fit_transform(X)

# Supervised (用 cell type label)
umap_sup = UMAP(target_metric="categorical").fit_transform(X, y=cell_types)

12.2 應用情境

12.2 Use cases

  • reference atlas 建立: 已 annotate 的細胞→ 用 supervised UMAP 得乾淨 reference
  • Reference atlas building: use annotated cells → supervised UMAP for clean reference
  • label transfer: 訓 supervised reference → 把新 sample 細胞 query 進去
  • Label transfer: train supervised reference → query new sample cells
  • 視覺化 cell type 之間的「邊界細胞」: 看哪些 cells 介於兩 type 之間
  • Visualize "boundary cells" between types: see which cells lie between two types
注意Caution: supervised UMAP 會強行分開 label 不同的細胞，可能掩蓋真實生物學的「過渡細胞」存在。Discovery research 不建議用，只在已知 label 的下游 visualization 用。 supervised UMAP force-separates cells with different labels, potentially masking real "transitional cells" in biology. Not for discovery research; only for downstream visualization of known labels.
