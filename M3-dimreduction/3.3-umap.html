UMAP：流形學習與模糊單純複形

UMAP: Manifold Learning & Fuzzy Simplicial Sets

UMAP 的範疇論基礎其實不嚇人。為什麼它比 t-SNE 更保留全局結構？cross-entropy 從哪來？

UMAP's category theory isn't scary. Why it preserves global structure better than t-SNE. Where does cross-entropy come from?

直覺 / Intuition

兩個關鍵假設

Two key assumptions

  1. 資料在低維流形上：高維資料其實「住在」一個低維彎曲表面
  2. 流形局部均勻分布：所以可以用「最近鄰距離」當作「局部尺度」校正
  1. Data lie on a low-D manifold: high-D data live on a low-D curved surface
  2. Manifold is locally uniform: nearest-neighbor distances give a local scale correction
核心數學 / Math

高維圖：fuzzy simplicial set

High-D graph: fuzzy simplicial set

對每個點 $i$，定義「邊權重」：

For each point $i$, define edge weights:

$$w_{j|i} = \exp\left(-\frac{\max(0, d(x_i, x_j) - \rho_i)}{\sigma_i}\right)$$
$\rho_i$ = 第 1 近鄰的距離（「局部尺度」），$\sigma_i$ 用二分搜尋讓 $\sum_j w_{j|i} = \log_2(k)$
$\rho_i$ = distance to 1st neighbor (local scale); $\sigma_i$ tuned so $\sum_j w_{j|i} = \log_2(k)$

對稱化（fuzzy union）：

Symmetrize (fuzzy union):

$$\mu_{ij} = w_{j|i} + w_{i|j} - w_{j|i} \cdot w_{i|j}$$

這個 $\mu_{ij} \in [0, 1]$ 解讀為「邊 $(i,j)$ 屬於『流形圖』的模糊隸屬度」。

$\mu_{ij} \in [0,1]$ is the "fuzzy membership" of edge $(i,j)$ in the manifold graph.

📐 為什麼用「減第一近鄰距離」？ 📐 Why subtract first-neighbor distance?

這是流形假設的關鍵。如果 $i$ 周圍非常密，那麼「跟最近鄰差不多遠的點」應該都算「同樣親近」。$\rho_i$ 把局部密度差異消除，所有局部都被「重新校準成同樣尺度」。

Key manifold assumption. If $i$'s neighborhood is dense, points "as far as the nearest neighbor" all count as "equally close". $\rho_i$ normalizes local density variations.

低維邊權重

Low-D edge weights

$$\nu_{ij} = \left(1 + a \|y_i - y_j\|^{2b}\right)^{-1}$$
$a, b$ 預設由 min_dist 與 spread 擬合決定
$a, b$ fitted from min_dist and spread

目標：cross-entropy

Objective: cross-entropy

$$\text{CE}(\mu, \nu) = \sum_{i \neq j} \left[ \mu_{ij} \log \frac{\mu_{ij}}{\nu_{ij}} + (1-\mu_{ij}) \log \frac{1-\mu_{ij}}{1-\nu_{ij}} \right]$$

兩項：第一項拉近真正鄰居（attractive force），第二項推開非鄰居（repulsive force）。比 t-SNE 的 KL 多了第二項，這是 UMAP 保留全局結構更好的關鍵。

Two terms: attractive (real neighbors), repulsive (non-neighbors). The second term — absent in t-SNE's KL — is why UMAP preserves global structure better.

優化：負取樣 + SGD

Optimization: negative sampling + SGD

不用算全部 $n^2$ 對。每步隨機選一條真實邊（吸引）+ 5 個隨機點（排斥），用 SGD 更新位置。複雜度 $O(n \cdot k)$，遠快於 t-SNE。

Avoids $n^2$ pairs. Each step: one real edge (attraction) + 5 random points (repulsion), SGD update. Complexity $O(n \cdot k)$, far faster than t-SNE.
