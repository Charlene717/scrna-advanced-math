M5.3 · STATISTICAL INFERENCE

細胞型態分類器

Cell Type Classifiers

怎麼從「reference 資料集」變成可用的分類器？SingleR、CellTypist、scANVI 的數學原理。

Turning reference datasets into classifiers. The math of SingleR, CellTypist, scANVI.

直覺 / Intuition

Annotation 有兩條路：(1) marker-based（手工挑 marker genes 評分）；(2) reference-based（用標好的 atlas 訓練分類器）。後者是現代主流。

Two routes: (1) marker-based (score curated markers); (2) reference-based (train classifier from annotated atlas). The latter is modern default.

核心數學 / Math

① SingleR — Spearman 相關性— Spearman correlation

把 query 細胞與 reference 中每個細胞型態的「典型表現量」算 Spearman 相關，最高分為分類。然後用「fine-tuning」迭代縮小候選集。

Spearman correlation between query cell and "typical expression" of each reference cell type. Highest score wins. Iterative fine-tuning refines candidates.

$$\hat{c}(q) = \arg\max_c \, \rho_{\text{Spearman}}(q, \bar{r}_c)$$

② CellTypist — 邏輯回歸 + SGD

每個細胞型態訓練一個 one-vs-rest 邏輯回歸：

One-vs-rest logistic regression per cell type:

$$P(y = c \mid \mathbf{x}) = \sigma(\mathbf{w}_c^\top \mathbf{x} + b_c), \quad \sigma(z) = \frac{1}{1+e^{-z}}$$ $$\hat{c}(\mathbf{x}) = \arg\max_c P(y = c \mid \mathbf{x})$$

參數用 L2 正則化 SGD 訓練，可處理百萬細胞 atlas。

Trained with L2-regularized SGD, scales to million-cell atlases.

③ scANVI — 半監督 VAE— semi-supervised VAE

擴展 scVI（M6 會用到的深度模型）讓未標註細胞也參與訓練。核心是 ELBO 加上分類損失：

Extends scVI to use unlabeled cells. ELBO with classification term:

$$\mathcal{L} = \underbrace{\mathbb{E}_{q(z|x)}[\log p(x|z)] - \text{KL}(q(z|x) \| p(z))}_{\text{ELBO}} + \alpha \cdot \mathbb{E}[\log p(y|z)]$$

$z$ = 潛在表示（拿掉 batch effect 後）、$y$ = 細胞型態標籤。對於未標註細胞只用 ELBO 那部分。

$z$ = latent representation (batch-corrected); $y$ = cell type. Unlabeled cells only contribute to ELBO.

程式碼 / Code 
import celltypist
predictions = celltypist.annotate(adata, model="Immune_All_Low.pkl")
adata.obs["celltypist"] = predictions.predicted_labels

# scANVI
import scvi
scvi.model.SCANVI.setup_anndata(adata, labels_key="cell_type", unlabeled_category="Unknown")
model = scvi.model.SCANVI(adata)
model.train()

library(SingleR); library(celldex)
ref <- HumanPrimaryCellAtlasData()
pred <- SingleR(test = as.SingleCellExperiment(pbmc), ref = ref, labels = ref$label.main)
pbmc$cell_type <- pred$labels
