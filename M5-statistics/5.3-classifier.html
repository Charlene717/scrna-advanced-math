細胞分類器：自動 annotate 細胞型態

Cell Classifier: automated cell-type annotation

Leiden 給你 10 個 cluster，DE 給你每群的 marker gene list。但「cluster 3 高表現 CD3D」這個事實本身不會自動告訴你那是 T 細胞—— 你還是要查 marker → 細胞型態對應表，手動 label。

這節介紹自動 annotation 工具： 從邏輯回歸 + softmax 的數學基礎開始，理解 CellTypist 怎麼用「reference + 邏輯回歸」極快 annotate； scNym 怎麼用半監督學習 transfer 跨資料； 最後談 confidence score 跟「reject option」（拒絕標籤）的設計。
Leiden gives 10 clusters; DE gives marker gene lists. But "cluster 3 has high CD3D" doesn't automatically say it's T cells — you still need a marker → cell-type lookup, manually.

Automated annotation tools: starting from logistic regression + softmax math, how CellTypist uses "reference + logistic regression" for fast annotation; scNym's semi-supervised transfer across datasets; finally confidence scores and "reject option" (refusing to label).

§1 marker-based vs reference-based 對比marker-based vs reference-based

1.1 marker-based 的計分方式

1.1 marker-based scoring

SCSA 等工具用一個簡單分數：

SCSA-style tools use a simple score:

$$\text{score}(c, t) = \sum_{g \in \mathcal{M}_t} \mathbb{1}\{g \in \mathcal{M}_c\}$$
$\mathcal{M}_c$ = cluster $c$ 的 top marker；$\mathcal{M}_t$ = cell type $t$ 的已知 marker
$\mathcal{M}_c$ = cluster $c$'s top markers; $\mathcal{M}_t$ = cell type $t$'s known markers

挑「分數最高的細胞型態」當答案。簡單但問題不少：marker 重疊（CD8+ T 跟 NK 都表現 GZMB）、未知 subtype 沒對應。

Pick the highest-scoring cell type. Simple but problematic: marker overlap (CD8+ T and NK both express GZMB), unknown subtypes have no entry.

1.2 reference-based 的優勢

1.2 reference-based advantages

關鍵Key: 用全表現量向量當特徵（不只 top marker），用機器學習把 query 細胞投影到「已知細胞型態」space。 能利用 weak signals（很多個基因各微小差）跟連續特徵（不只 binary）。 Use full expression vector as features (not just top markers), ML maps query cells to "known cell-type" space. Leverages weak signals (many genes each contributing slightly) and continuous features.

§2 邏輯回歸與 softmax 數學Logistic regression & softmax math

CellTypist 用多類邏輯回歸（multinomial logistic regression）。每個細胞型態 $t$ 有一個權重向量 $\mathbf{w}_t \in \mathbb{R}^d$（每個 gene 一個 weight）。 給細胞表現量 $\mathbf{x}$，分類為 $t$ 的機率：

CellTypist uses multinomial logistic regression. Each cell type $t$ has weight vector $\mathbf{w}_t \in \mathbb{R}^d$ (one per gene). Given expression $\mathbf{x}$, probability of class $t$:

$$P(y = t \,|\, \mathbf{x}) = \frac{\exp(\mathbf{w}_t^\top \mathbf{x} + b_t)}{\sum_{t'} \exp(\mathbf{w}_{t'}^\top \mathbf{x} + b_{t'})}$$
分子 = 細胞型態 $t$ 的「score」、分母 normalize 使機率加總 = 1
numerator = cell type $t$'s score, denominator normalizes to sum 1

2.1 訓練：最大化 likelihood

2.1 Training: maximize likelihood

$$\mathcal{L} = -\sum_i \log P(y_i \,|\, \mathbf{x}_i) + \lambda \sum_t \|\mathbf{w}_t\|_1$$
cross-entropy loss + L1 正則化（讓 $\mathbf{w}_t$ 稀疏，自動選 marker）
cross-entropy + L1 reg (sparse $\mathbf{w}_t$, auto-selects markers)

關鍵：L1 正則讓每個細胞型態 $t$ 的 $\mathbf{w}_t$ 變稀疏—— 只剩~50-200 個 gene 有非零權重。非零權重的 gene 就是這個型態的學到的 marker，可解釋。

Key: L1 regularization makes $\mathbf{w}_t$ sparse — only ~50–200 non-zero genes per cell type. Non-zero genes are the learned markers, interpretable.

§3 互動：softmax 多類分類Interactive softmax

假設你有一個新 query 細胞跟 4 種已知細胞型態。每型有一個 score（你拉滑桿改變）。softmax 把 score 轉成機率。觀察：

A query cell vs 4 known cell types. Each type has a score (drag sliders). Softmax converts scores → probabilities. Observe:

  • 最高 score 對應最高機率（贏家）
  • highest score → highest probability (winner)
  • score 之間「差距」越大，最高機率越接近 1（信心強）
  • larger score gaps → winner probability closer to 1 (confident)
  • score 都很接近 → 機率分散（不確定）
  • close scores → spread probability (uncertain)

Entropy 是「不確定性」指標：值越大表越不確定（多型態同分）；接近 0 表示某型態獨贏。

Entropy measures uncertainty: higher = less certain (multiple classes tied); near 0 = one class dominates.

§4 CellTypist 訓練流程CellTypist training pipeline

CellTypist（Domínguez Conde et al. 2022）是個訓練好的 logistic regression model 庫，覆蓋 30+ 預訓練模型（免疫、腦、發育...）。

CellTypist (Domínguez Conde et al. 2022) is a library of pretrained logistic regression models covering 30+ tissues (immune, brain, development...).

4.1 訓練 5 步

4.1 5-step training

  1. 收集已 annotate 的 reference data（如 Human Cell Atlas） Collect annotated reference (e.g., Human Cell Atlas)
  2. log1p normalizelog1p normalize
  3. SGD 訓練 multinomial logistic regression with L1 SGD-train multinomial logistic regression with L1
  4. over-clustering：把每個訓練 cluster 再分小，捕捉 subtypes over-clustering: re-cluster within each training cluster to capture subtypes
  5. 輸出每細胞型態的稀疏權重向量 Output sparse weight vector per cell type

4.2 使用

4.2 Usage

import celltypist

# load pretrained model (immune cells, low-resolution)
model = celltypist.models.Model.load("Immune_All_Low.pkl")

# predict on your data (must be log1p-normalized)
predictions = celltypist.annotate(adata, model=model, majority_voting=True)
adata = predictions.to_adata()

# adata.obs["predicted_labels"] 即為細胞型態
# adata.obs["majority_voting"] 是 cluster-level 投票結果（更穩定）
majority voting 的妙處Beauty of majority voting: 單細胞層級的預測有噪音；用 cluster 內多數票讓整個 cluster 拿同一個 label，跟 Leiden 的天然 cluster 結構對齊。 Single-cell predictions are noisy; cluster-wise majority voting gives the whole cluster one label, aligning with Leiden's natural structure.

§5 scNym 半監督學習scNym semi-supervised

CellTypist 是純 supervised：只用 labeled reference 訓練。 問題：你的 query data 可能跟 reference 不同 batch / 不同平台 / 不同物種—— domain shift 讓 supervised 模型表現變差。

scNym（Kimmel & Kelley 2021）用半監督：在訓練時同時看「labeled reference + unlabeled query」， 用 MixUp 跟 對抗訓練 讓模型對 domain shift 穩健。

CellTypist is purely supervised: trained on labeled reference only. Problem: your query may differ from reference in batch / platform / species — domain shift degrades supervised models.

scNym (Kimmel & Kelley 2021) is semi-supervised: trains on "labeled reference + unlabeled query" together, using MixUp and adversarial training for domain robustness.

§6 Confidence 與 reject optionConfidence & reject option

Softmax 給每個細胞一個機率分布。但「最高機率 = 0.3」跟「最高機率 = 0.95」差很多——前者其實是「不知道」，後者才是「有信心」。 好的分類器應該拒絕回答 (reject option) 當信心不足。

Softmax gives a probability distribution per cell. "max prob = 0.3" vs "max prob = 0.95" differ greatly — the former is really "don't know", the latter "confident". A good classifier should refuse to answer (reject option) when uncertain.

6.1 兩種信心指標

6.1 Two confidence metrics

$$\text{max-prob} = \max_t P(y = t \,|\, \mathbf{x})$$ $$\text{entropy} = -\sum_t P(y = t \,|\, \mathbf{x}) \log P(y = t \,|\, \mathbf{x})$$

CellTypist 預設用 max-prob。當細胞 max-prob < threshold（如 0.5），標為 "Unassigned"。

CellTypist defaults to max-prob. When max-prob < threshold (e.g., 0.5), label as "Unassigned".

6.2 為什麼有 Unassigned 是好事

6.2 Why "Unassigned" is good

兩種「不確定」情境Two "uncertain" scenarios: (1) 罕見或新細胞型態（reference 沒有）；(2) Doublet / 過渡細胞（兩種型態之間）。兩種都應該被標 Unassigned 而不是強塞一個答案。 (1) rare or novel cell types (not in reference); (2) doublets / transitional cells (between types). Both should be flagged "Unassigned" rather than force-labeled.

§9 SingleR：用 Spearman correlation 做 reference mappingSingleR: Spearman correlation reference mapping

SingleR（Aran 2019）用不同的數學做 annotation：對 query cell vs reference cell type，算Spearman 相關，挑最高相關 type 當答案。

SingleR (Aran 2019) uses different math: compute Spearman correlation between query cell and each reference type, pick highest.

9.1 演算法

9.1 Algorithm

  1. 對每 reference cell type，算 marker gene set（top variable） Per reference type, compute marker gene set (top variable)
  2. 對 query cell $i$ 跟 reference type $t$，算 Spearman $\rho_{it}$ For query cell $i$ and reference type $t$, Spearman $\rho_{it}$
  3. 挑 max $\rho_{it}$ 的 type 當預測 Pick type with max $\rho_{it}$
  4. Fine-tuning：只用 top 25% types 之間的差異 gene 重算 → 提高解析度 Fine-tuning: recompute using only differing genes among top 25% types → higher resolution

§10 scANVI：半監督 VAE for label transferscANVI: semi-supervised VAE for label transfer

scANVI（Xu et al. 2021）擴展 scVI 加上「label classification head」：在 latent z 上同時做 batch correction + cell type classification。

scANVI (Xu et al. 2021) extends scVI with a "label classification head": joint batch correction + cell type classification on latent z.

10.1 模型

10.1 Model

$$z = f_{\text{enc}}(x, s), \quad \hat{y} = g_{\text{classifier}}(z), \quad x \sim \text{NB}(f_{\text{dec}}(z, s, \hat{y}))$$
$s$ = batch label、$y$ = cell type label（known or unknown）
$s$ = batch label, $y$ = cell type label (known or unknown)

10.2 訓練 loss

10.2 Training loss

$$\mathcal{L} = \mathcal{L}_{\text{VAE}} + \lambda \cdot \mathcal{L}_{\text{classification}}$$
labeled cells 用 cross-entropy；unlabeled 用 expectation
labeled cells use cross-entropy; unlabeled use expectation
為何 semi-supervised 在 scRNA 強 Why semi-supervised excels in scRNA: 你有 100k unlabeled query + 10k labeled reference。scANVI 同時學「batch effect 在 latent z 怎麼移除」+「cell type 在 latent z 怎麼分」，兩個任務互相強化。對跨平台(10x v3 → Smart-seq2) 跟跨物種(mouse → human) 表現特別好。 You have 100k unlabeled query + 10k labeled reference. scANVI jointly learns "how batch is removed in z" + "how cell types separate in z", tasks mutually reinforce. Excels on cross-platform (10x v3 → Smart-seq2) and cross-species (mouse → human).
