M5.2 · STATISTICAL INFERENCE

多重檢定校正：FDR

Multiple Testing & FDR

2 萬個基因做 t 檢定為什麼會「滿地都是顯著」？FWER vs FDR、BH 程序的證明。

Why 20k simultaneous tests yield bogus significance. FWER vs FDR. Proof sketch of BH.

直覺 / Intuition

對 2 萬個基因每個做 t 檢定，即使沒有真實差異，仍會有 1,000 個 p < 0.05（純粹巧合）。如果不校正，DE 結果幾乎全是假陽性。

20,000 t-tests yield ~1,000 false positives at α=0.05 even under null. Without correction, DE results are mostly noise.

核心數學 / Math

FWER (Family-Wise Error Rate)

$$\text{FWER} = P(\text{至少一個假陽性 / at least one FP})$$

Bonferroni 校正：要 FWER ≤ α，每個檢定用 $\alpha/m$ 當門檻。

Bonferroni: for FWER ≤ α, threshold each test at $\alpha/m$.

$$\text{Bonferroni: reject } H_i \iff p_i \leq \alpha / m$$

問題：太嚴格。$m=20,000$ 時 Bonferroni 要 $p_i \leq 2.5 \times 10^{-6}$——真的差異也常被砍掉。

Issue: too strict. With $m=20,000$, requires $p_i \leq 2.5 \times 10^{-6}$ — kills real signal.

FDR (False Discovery Rate)

$$\text{FDR} = E\left[\frac{V}{R}\right]$$
$V$ = 假陽性數、$R$ = 被宣告陽性數
$V$ = false positives, $R$ = declared positives

控制「被宣告為陽性中，假陽性的比例」——不是「有沒有假陽性」。 生物學家更在意這個——「我手上這 100 個 DE genes，期望有幾個是真的」。

Controls "fraction of declared positives that are false" — not "any false positive at all". Biologically meaningful.

Benjamini-Hochberg 程序procedure

# Step 1: 排序 p-values p_(1) ≤ p_(2) ≤ ... ≤ p_(m) # Step 2: 找最大的 k 使得 find max k s.t. p_(k) ≤ k · α / m # Step 3: 拒絕前 k 個假設 reject H_(1), ..., H_(k)

BH 的證明（直覺）：在獨立或正相關下，BH 程序保證 $\text{FDR} \leq \alpha$。
關鍵想法：把 $p_{(k)}$ 與 $k\alpha/m$ 比較相當於問「前 k 個發現中，預期會有多少是隨機產生的」。

BH proof intuition: under independence or PRDS, $\text{FDR} \leq \alpha$. Comparing $p_{(k)}$ vs $k\alpha/m$ asks "among top k discoveries, how many are expected by chance".

q-value 的解讀interpretation

每個基因的 BH-adjusted p-value 稱 q-value。q = 0.05 意義是：「把此 q 值當門檻，期望中有 5% 的『陽性』其實是假的」。

BH-adjusted p-value = q-value. q = 0.05 means: "thresholding at this q, expected FDR is 5%".

📝 Storey q-value 改進📝 Storey q-value refinement

Storey (2002) 引入 $\hat\pi_0$（真實 null 假設的比例估計），把 BH 程序改良為：$q_i = \hat\pi_0 \cdot p_i \cdot m / k_i$。在 scRNA-seq 高比例「無差異基因」情境下更不保守。

Storey (2002) introduces $\hat\pi_0$ (proportion of true nulls), refining BH as $q_i = \hat\pi_0 \cdot p_i \cdot m / k_i$. Less conservative when many true nulls exist.

程式碼 / Code 
from statsmodels.stats.multitest import multipletests
reject, pvals_adj, _, _ = multipletests(pvals, alpha=0.05, method="fdr_bh")

# Scanpy 自動加 padj
sc.tl.rank_genes_groups(adata, "leiden", method="wilcoxon")
# adata.uns["rank_genes_groups"]["pvals_adj"]

# Base R
padj <- p.adjust(pvals, method = "BH")

# Storey q-value
library(qvalue)
qobj <- qvalue(pvals)
qobj$qvalues
qobj$pi0       # 估計的真實 null 比例
