多重檢定與 FDR：從 Bonferroni 到 BH

Multiple Testing & FDR: from Bonferroni to BH

DE 分析一次測 20,000 個 gene 的 p-value。在沒有真實差異的情況下，按 α = 0.05 的標準， 你會純粹由隨機得到 1,000 個「顯著」的 gene——全是假陽性。

這節從這個悖論出發，理解 family-wise error rate (FWER) 跟 false discovery rate (FDR) 的差別， 推導 Bonferroni 為何過於保守，介紹 BH (Benjamini-Hochberg) 為何成為現代基因組學的標準， 最後談 Storey q-value 跟在 scRNA 怎麼正確報告 marker。
DE testing runs 20,000 p-values at once. With no true differences, at α = 0.05, you'd get 1,000 "significant" genes purely by chance — all false positives.

Starting from this paradox: family-wise error rate (FWER) vs false discovery rate (FDR), why Bonferroni is too conservative, why BH (Benjamini-Hochberg) became the genomics standard, Storey's q-value, and how to correctly report markers in scRNA.

🧬 scRNA-seq 視角：FDR 是「marker 清單能不能信」的安全閥 🧬 scRNA-seq perspective: FDR is the safety valve deciding whether your marker list is trustworthy

📍 在 scRNA-seq 流程中的位置Position in scRNA-seq pipeline

Leiden → DE tests → FDR / multiple testing (BH) → significant marker list → annotation / pathway / disease vs control

scRNA-seq DE 一次跑每 cluster × 30k gene = 數十萬 p-value。沒 FDR，1500-15000 個 gene 會被「隨機標記成 marker」。FDR 是把「DE 結果是不是垃圾」量化的唯一機制。 scRNA-seq DE runs each cluster × 30k genes = hundreds of thousands of p-values. Without FDR, 1500-15000 genes get "randomly tagged as markers". FDR is the only mechanism to quantify whether DE results are noise or signal.

🎯 為什麼 scRNA 必須做 FDR、且必須用 BH（不用 Bonferroni）Why scRNA MUST do FDR, and MUST use BH (not Bonferroni)

  • scRNA gene 數量極大，假陽性問題比 bulk 嚴重 10 倍scRNA has many more genes; FP problem 10× worse than bulk： bulk RNA-seq 跑 1 個 contrast × 20k gene = 20k p-value。scRNA 跑 10 cluster × 30k = 300k p-value，假陽性是 bulk 的 15 倍。Bonferroni（α/m = 0.05/300k = 1.7e-7）太嚴，會把真 marker 砍光。 Bulk: 1 contrast × 20k = 20k p-values. scRNA: 10 cluster × 30k = 300k p-values, 15× worse. Bonferroni (α/m = 0.05/300k = 1.7e-7) is too strict, eliminates real markers.
  • scRNA marker 通常 effect size 很大，但 p-value 也由細胞數驅動 → BH 才平衡scRNA markers have large effect sizes but p-values inflated by cell count → BH balances： 10,000 個細胞做 Wilcoxon，即使輕微的差異都會跑出 p < 1e-300。BH 控制「報出的 marker 中假陽性的比例」而不是「絕對個數」→ 跟生物學家想知道的事情（「我這份 list 大概有多少 noise」）對齊。 Wilcoxon on 10,000 cells gives p < 1e-300 for trivial differences. BH controls "fraction of false positives among reported markers" not "absolute count" → aligns with what biologists want to know ("how much noise in my list").
  • 每 cluster 獨立 BH or 全 cluster 聯合 BH 結果不同Per-cluster vs joint BH gives different results： scanpy 預設每 cluster 獨立做 BH（rank_genes_groups），生物上合理但跨 cluster 比較需要小心。報告時要明確說明 FDR scope。 scanpy defaults to per-cluster BH (rank_genes_groups), reasonable biologically but cross-cluster comparisons need care. Must explicitly state FDR scope in papers.

§0 故事：1000 個假陽性Story: 1000 false positives

考慮一個極端的情境：你跑 DE 比較 cluster 0 vs cluster 1。 但假設這兩群其實是同一個細胞型態（你誤分群了）——所以真實沒有任何差異基因。 你還是會得到 20,000 個 p-value。在 α = 0.05 的門檻下，會有多少個 p < 0.05？

Extreme scenario: you compare cluster 0 vs cluster 1 with DE. Suppose these are actually the same cell type (misclustering) — so no true DE genes. You still get 20,000 p-values. At α = 0.05, how many are p < 0.05?

$$E[\text{false positives}] = m \cdot \alpha = 20{,}000 \times 0.05 = 1{,}000$$

期望值就是 1,000 個假陽性。即使所有真實效應 = 0，你的「marker list」還是有 1000 個 gene。完全沒幫助。

1,000 false positives expected. Even with no real effects, your "marker list" still has 1000 genes — useless.

這就是「多重檢定問題」This is the "multiple testing problem": 當你同時測很多 hypothesis 時，「單一檢定」的 α = 0.05 不再對應整個結果的可信度。必須校正。 When testing many hypotheses, "single-test" α = 0.05 no longer reflects overall reliability. Correction required.

1.1 直覺差別

1.1 Intuitive difference

FWER: 「我能接受整個分析有 5% 機率產生任何一個假陽性嗎？」非常嚴格——一份報告若 100% 不犯任何錯。 "Can I accept a 5% chance of any single false positive in the entire analysis?" Very strict — like a 100% error-free report.
FDR: 「在我宣告為『顯著』的 list 中，最多容忍 5% 是假的。」更實際——基因組學接受「list 中有少數假陽性」，但要控制比例。 "Within my 'significant' list, tolerate ≤ 5% being false." More practical — genomics accepts some false positives in the list, but bounds the proportion.

§2 Bonferroni：保證 FWERBonferroni: control FWER

$$\text{Reject } H_0^{(i)} \iff p_i < \frac{\alpha}{m}$$
每個檢定用「α / m」當門檻
Use "α / m" as threshold per test

2.1 推導：Union bound

2.1 Derivation: union bound

$$P(\text{any FP}) = P\!\left(\bigcup_i \{p_i < \alpha/m\}\right) \le \sum_i P(p_i < \alpha/m) = m \cdot \frac{\alpha}{m} = \alpha$$

所以 Bonferroni 保證 FWER ≤ α。對 20,000 個 gene 取 α = 0.05 → 每基因門檻是 p < 2.5 × 10⁻⁶。

Bonferroni guarantees FWER ≤ α. For 20,000 genes at α = 0.05 → per-gene threshold is p < 2.5 × 10⁻⁶.

2.2 為什麼太嚴？

2.2 Why too strict?

scRNA 真實 T cell vs B cell 比較，可能 1000 個真實 DE gene。Bonferroni 校正後， 弱訊號（log2FC ~ 1，p ~ 10⁻³）全部變不顯著，你只剩下「明顯到不用統計就知道」的 50 個強 gene。資訊大量流失。

For a real T vs B comparison, perhaps 1000 truly DE genes. After Bonferroni, weak signals (log2FC ~ 1, p ~ 10⁻³) all become non-significant; only ~50 "obvious-without-stats" strong genes remain. Massive information loss.

§3 互動：p-value 分布的線索Interactive: p-value distribution

在沒有真實效應下，p-value 服從 Uniform(0, 1)——histogram 應該是平的。 有真實效應的 gene 會在左側（小 p）堆積一個峰。BH / Storey 就利用這個結構。

Under no true effects, p-values follow Uniform(0, 1) — flat histogram. Truly DE genes pile up on the left (small p). BH / Storey exploit this structure.

解讀：左側那個峰就是真實 DE gene 集中的地方。右側「flat 部分」對應的高度 ≈ π₀ × m / nBin，告訴你「平均每 bin 有多少 null 噪音」。
Reading it: Left peak = true DE genes. The "flat right region" height ≈ π₀ × m / nBin tells you "average null noise per bin".

§4 BH 演算法：控制 FDRBH: control FDR

Benjamini & Hochberg 1995 的天才設計：用升序排序的 p-value 跟一個遞增門檻比較。

Benjamini & Hochberg 1995's brilliant design: compare sorted p-values to an increasing threshold.

4.1 演算法

4.1 Algorithm

  1. 排序：Sort: $p_{(1)} \le p_{(2)} \le \cdots \le p_{(m)}$
  2. 對每個 $i$，比較 $p_{(i)}$ 跟 $\frac{i}{m} \alpha$： For each $i$, compare $p_{(i)}$ to $\frac{i}{m} \alpha$:
$$k^* = \max\!\left\{ i : p_{(i)} \le \frac{i}{m} \alpha \right\}$$ $$\text{Reject } H_0^{(1)}, H_0^{(2)}, \ldots, H_0^{(k^*)}$$

即「找到滿足 $p_{(i)} \le \frac{i}{m} \alpha$ 的最大排名 $k^*$」，然後拒絕排名 1 到 $k^*$ 的所有檢定。

"Find the largest rank $k^*$ satisfying $p_{(i)} \le \frac{i}{m} \alpha$", then reject all tests ranked 1 to $k^*$.

4.2 為什麼這樣能控制 FDR？

4.2 Why does this control FDR?

直覺：當所有檢定都是 null時，p-value 是 Uniform，第 $i$ 小的 p-value 期望值 $\approx i/m$。 所以 BH 的門檻 $i/m \cdot \alpha$ 正是「null 情境下你會看到的 p × α」。 真實 DE gene 的 p 比 null 小很多，所以會在門檻線下穿越。

Intuition: under all null, p-values are uniform — the $i$-th smallest has expected value $\approx i/m$. So BH's threshold $i/m \cdot \alpha$ is "the p you'd see under null, times α". True DE p-values are much smaller, crossing the threshold line.

▸ Benjamini-Hochberg 1995 證明大意 ▸ Sketch of Benjamini-Hochberg 1995 proof

在獨立檢定下，可以證明：BH 程序的期望 FDR = $\pi_0 \cdot \alpha \le \alpha$，其中 $\pi_0$ 是「真正 null」的比例。 所以實際 FDR 通常嚴格低於 α（因為 $\pi_0 < 1$）。在 PRDS（positive regression dependent on subset）下也成立。

Under independent tests, one can show: BH's expected FDR = $\pi_0 \cdot \alpha \le \alpha$, where $\pi_0$ is the "true null" proportion. So actual FDR is usually strictly below α (since $\pi_0 < 1$). Also holds under PRDS (positive regression dependent on subset).

§6 Storey q-valueStorey q-value

BH 假設 $\pi_0 = 1$（所有檢定都是 null），是保守估計。Storey (2003) 改用實際估計 $\pi_0$，獲得更大檢定力。

BH assumes $\pi_0 = 1$ (all tests null) — conservative. Storey (2003) estimates $\pi_0$ for higher power.

6.1 怎麼估 π₀?

6.1 Estimating π₀

看 p-value histogram 的右側 flat 部分（例如 p > 0.5）：

Look at the flat right portion of the p-value histogram (e.g., p > 0.5):

$$\hat{\pi}_0(\lambda) = \frac{\#\{p_i > \lambda\}}{m(1-\lambda)}, \quad \lambda \in [0.4, 0.6]$$
通常 $\lambda = 0.5$；估計「null gene 占比」
typically $\lambda = 0.5$; estimates "null proportion"

6.2 q-value 定義

6.2 q-value definition

$$q_i = \min_{t \ge p_i} \, \widehat{\text{FDR}}(t)$$
即「如果把這個 p 當門檻，預期 FDR 是多少」
"if you used this p as threshold, what FDR would you have?"
解讀Reading: 「q = 0.05 的 gene 加入 list 時，整個 list 的預期 FDR 是 5%。」這是每基因獨立的 FDR 解讀。 "Adding this q=0.05 gene to the list keeps the list's expected FDR at 5%." Per-gene FDR interpretation.

§9 深入：Benjamini-Hochberg 1995 完整證明大綱Deep dive: Benjamini-Hochberg 1995 full proof sketch

§4 給了 BH 演算法。本節證明「BH 真的控制 FDR ≤ α」這個關鍵結論——理解後你會真的相信這個方法。

§4 gave the BH algorithm. We prove "BH actually controls FDR ≤ α" — once you understand this, you'll truly trust the method.

9.1 設定

9.1 Setup

$m$ 個獨立假設檢定，其中 $m_0$ 個是 null（H₀ 真），$m_1 = m - m_0$ 個是 alternative。 排序 p-value：$p_{(1)} \le p_{(2)} \le \cdots \le p_{(m)}$。 BH 找最大的 $k^* = \max\{i : p_{(i)} \le i\alpha/m\}$，拒絕 rank 1 到 $k^*$。

$m$ independent tests, of which $m_0$ are null and $m_1 = m - m_0$ are alternative. Sort p-values: $p_{(1)} \le p_{(2)} \le \cdots \le p_{(m)}$. BH finds largest $k^* = \max\{i : p_{(i)} \le i\alpha/m\}$, rejects rank 1 to $k^*$.

9.2 證明大綱

9.2 Proof sketch

關鍵 lemma：對 null hypothesis $H_0^{(i)}$，$P_i$ 在 H₀ 下是 Uniform(0,1)。考慮事件「第 $i$ 個 null hypothesis 被拒絕」：

Key lemma: under $H_0^{(i)}$, $P_i$ is Uniform(0,1). Consider event "null hypothesis $i$ is rejected":

$$E[\text{FDR}] = E\!\left[\frac{V}{\max(R, 1)}\right] = \sum_{i \in H_0} E\!\left[\frac{\mathbb{1}\{i \text{ rejected}\}}{R \vee 1}\right]$$
$V$ = 假陽性數、$R$ = 總拒絕數
$V$ = # false positives, $R$ = # rejections

用「step-up」性質：BH 拒絕 rank 1..k* → $R = k^*$ → $p_{(k^*)} \le k^* \alpha / m$。對每個 null $H_0^{(i)}$：

Step-up property: BH rejects rank 1..k* → $R = k^*$ → $p_{(k^*)} \le k^* \alpha / m$. For each null $H_0^{(i)}$:

$$E\!\left[\frac{\mathbb{1}\{p_i \le R\alpha/m\}}{R}\right] = \frac{\alpha}{m} \cdot E\!\left[\frac{\mathbb{1}\{p_i \le R\alpha/m\}}{R \alpha / m}\right] \le \frac{\alpha}{m}$$

加總所有 $m_0$ 個 null 得：

Sum over all $m_0$ nulls:

$$E[\text{FDR}] \le \frac{m_0}{m} \cdot \alpha \le \alpha$$
BH 嚴格控制 FDR ≤ α，等號當 $m_0 = m$（全 null）
BH strictly controls FDR ≤ α, equality when $m_0 = m$ (all null)
後續推廣Subsequent extensions: 原證明假設 independence；Benjamini & Yekutieli (2001) 推廣到 positive regression dependence (PRDS)（許多 scRNA 情境符合）。對任意依賴改用 BY procedure（更嚴格）。 Original assumes independence; Benjamini & Yekutieli (2001) extended to positive regression dependence (PRDS), covering many scRNA scenarios. For arbitrary dependence, use BY procedure (stricter).

📚 References: Benjamini & Hochberg (1995) JRSS B 57:289 (original proof); Benjamini & Yekutieli (2001) Ann Stat 29:1165 (BY extension); Storey (2002) JRSS B 64:479 (q-value).

§11 BY procedure 跟 IHW：BH 的進階替代BY procedure and IHW: advanced BH alternatives

11.1 BY (Benjamini-Yekutieli 2001)

11.1 BY (Benjamini-Yekutieli 2001)

BH 假設 independence/PRDS。若任意依賴，用 BY：

BH assumes independence/PRDS. For arbitrary dependence, use BY:

$$k^* = \max\!\left\{ i : p_{(i)} \le \frac{i}{m \cdot c(m)} \alpha \right\}, \quad c(m) = \sum_{j=1}^{m} \frac{1}{j} \approx \log m$$

對 20,000 genes，$c(m) \approx 9.9$ → 等於把 α 切成 1/10。更嚴格但保證。

For 20,000 genes, $c(m) \approx 9.9$ → α effectively divided by 10. Stricter but guaranteed.

11.2 IHW (Ignatiadis 2016): Independent Hypothesis Weighting

11.2 IHW (Ignatiadis 2016): Independent Hypothesis Weighting

IHW 用「輔助 covariate」改善 power：對每 hypothesis 分配權重 $w_i$，先驗信心高的 gene 給更寬鬆的門檻。對 scRNA：gene 平均表現量、HVG score 都是合理 covariate。

IHW uses "auxiliary covariate" for better power: weight $w_i$ per hypothesis, high prior-confidence genes get looser threshold. For scRNA: gene mean expression, HVG score are good covariates.

§12 Local FDR (Efron 2008)：每個 gene 自己的 confidenceLocal FDR (Efron 2008): per-gene confidence

「q-value 0.05 = list 中 5% 是假」是 list-level。 Local FDR 給每個 gene 自己的「是 null 的機率」——更精準的個體判定。

"q-value 0.05 = 5% of list is false" is list-level. Local FDR gives per-gene "probability of being null" — more precise individual judgment.

$$\text{fdr}(z) = P(H_0 | Z = z) = \frac{\pi_0 \cdot f_0(z)}{f(z)}$$
$f_0$ = null 分布 (Gaussian)、$f$ = 整體 z-statistic 分布、$\pi_0$ = null 比例
$f_0$ = null distribution (Gaussian), $f$ = overall z-statistic distribution, $\pi_0$ = null proportion

直覺：給定觀察 z=3.5 的 gene，它「是 null」的機率是多少？這個 per-gene 解讀對 follow-up experimental validation 特別有用。

Intuition: given a gene with z=3.5, what's its probability of being null? This per-gene interpretation is especially useful for follow-up experimental validation.
