QC 統計：MAD 離群偵測

QC: MAD-based Outlier Detection

為什麼 QC 不用平均±2 標準差？MAD 為什麼比標準差更穩健？Scrublet 怎麼用模擬算 doublet 機率？

Why QC avoids ±2σ thresholds. Why MAD is more robust than σ. How Scrublet simulates doublet probability.

直覺 / Intuition

為什麼平均±標準差會「失靈」？

Why mean ± σ fails

QC 目的是過濾「壞細胞」——nFeature 太低（空 droplet）、MT% 太高（破裂死細胞）、nCount 過高（doublet）。 但這些「壞細胞」本身會把平均跟標準差拉走—— 用 mean ± 2σ 當門檻反而把「不夠壞」的細胞也保留下來。

解法：用中位數取代平均、用 MAD（中位數絕對偏差）取代標準差。 中位數 / MAD 不會被極端值拉走，是「穩健統計」(robust statistics) 的基本工具。

QC filters bad cells — low nFeature (empty droplets), high MT% (dying cells), high nCount (doublets). But these bad cells pull mean and σ themselves — using mean ± 2σ ironically retains less-bad outliers.

Solution: replace mean with median, σ with MAD (Median Absolute Deviation). Both are unaffected by extreme values — the foundation of robust statistics.

核心數學 / Math

MAD 的定義definition

$$\mathrm{MAD}(\mathbf{x}) = \mathrm{median}_i \left( \left| x_i - \mathrm{median}(\mathbf{x}) \right| \right)$$
中位數的「中位數絕對偏差」——對極端值不敏感
Median of absolute deviations from median — insensitive to extremes

為什麼是 1.4826？

Why the 1.4826 factor?

若資料其實是高斯分布，1.4826 × MAD 是 σ 的無偏估計。常數來自：

If data are Gaussian, 1.4826 × MAD is an unbiased estimator of σ. The constant comes from:

$$1.4826 = \frac{1}{\Phi^{-1}(0.75)} = \frac{1}{0.6745}$$
$\Phi^{-1}(0.75)$ 是標準常態的第 75 分位數
$\Phi^{-1}(0.75)$ is the 75th percentile of standard normal

QC 門檻設定

QC threshold

$$\text{離群} \iff \left| x_i - \mathrm{median}(\mathbf{x}) \right| > k \cdot \mathrm{MAD}(\mathbf{x})$$
常用 $k = 3$（對應 ~99% Gaussian）或 $k = 5$（保守）
Common: $k=3$ (~99% Gaussian) or $k=5$ (conservative)

QC 變數常先做 log 轉換才算 MAD，因為 nFeature / nCount 通常呈右偏分布。

QC variables are typically log-transformed before MAD computation, due to right-skewed distributions of nFeature / nCount.

核心數學 / Math

Scrublet：用模擬算 doublet 機率

Scrublet: Simulated Doublet Probability

關鍵想法：把細胞兩兩相加當作「合成 doublet」，看真實細胞在 PCA 空間中跟誰像。

Key idea: add cells in pairs to create "synthetic doublets", then check which real cells are similar in PCA space.

# Step 1: 模擬 doublets for r in range(n_simulated): i, j = random.sample(range(n_cells), 2) synthetic[r] = (X[i] + X[j]) # 兩細胞相加 # Step 2: 合併 + PCA combined = concat([X, synthetic]) Z = PCA(combined, n_components=30) # Step 3: 每個真實細胞算 KNN 中有幾個是模擬 doublet for i in range(n_cells): neighbors = kNN(Z[i], k=50) n_doublet_neighbors = sum(1 for j in neighbors if is_synthetic(j)) doublet_score[i] = n_doublet_neighbors / 50

最終的 doublet_score 經過閾值判定即得 doublet 標籤。閾值通常用 GMM 或固定分位數決定。

The final doublet_score is thresholded (via GMM or fixed quantile) to label doublets.

程式碼 / Code

實作範例

Code Examples

import scanpy as sc
import numpy as np
from scipy.stats import median_abs_deviation

sc.pp.calculate_qc_metrics(adata, percent_top=None, log1p=False, inplace=True)

def is_outlier(M, metric, nmads=5):
    x = M.obs[metric]
    med, mad = np.median(x), median_abs_deviation(x)
    return (x < med - nmads*mad) | (x > med + nmads*mad)

adata.obs["outlier"] = (
    is_outlier(adata, "log1p_total_counts", 5) |
    is_outlier(adata, "log1p_n_genes_by_counts", 5) |
    is_outlier(adata, "pct_counts_in_top_20_genes", 5)
)
adata = adata[~adata.obs.outlier].copy()

# Doublet 偵測
import scrublet as scr
scrub = scr.Scrublet(adata.X)
adata.obs["doublet_score"], adata.obs["predicted_doublet"] = scrub.scrub_doublets()

library(Seurat); library(scDblFinder)

# 基本 QC metrics
pbmc[["percent.mt"]] <- PercentageFeatureSet(pbmc, pattern = "^MT-")

# MAD-based filtering
qc_filter <- function(x, nmads = 5) {
  med <- median(x); m <- mad(x)
  x > med - nmads*m & x < med + nmads*m
}
keep <- qc_filter(log1p(pbmc$nCount_RNA)) &
        qc_filter(log1p(pbmc$nFeature_RNA)) &
        pbmc$percent.mt < 15
pbmc <- pbmc[, keep]

# scDblFinder（推薦的 R doublet 工具）
sce <- as.SingleCellExperiment(pbmc)
sce <- scDblFinder(sce)
pbmc$doublet_score <- sce$scDblFinder.score
