Normalization：從 CPM 到 Pearson Residuals

Normalization: from CPM to Pearson Residuals

QC 砍完壞細胞後，你手上的細胞 total_counts 還是差很多—— 細胞 A 有 8000 個 mRNA、細胞 B 只有 2000。 這不見得是生物差異，可能只是隨機抽樣深度不同（droplet 體積、capture efficiency）。 在後續比較細胞 vs 細胞之前，你要先把這個「測序深度」的雜訊先移除。

這節我們從最直觀的比例開始，推到 CPM、log1p， 再進到 Pearson residuals 用負二項模型把「平均-變異關係」一起處理掉。 每一步都會有互動圖讓你看到分布怎麼變。
After QC, the remaining cells still have very different total_counts — cell A may have 8000 mRNA, cell B only 2000. This isn't necessarily biology — it's often sequencing depth variation (droplet volume, capture efficiency). Before comparing cells, you have to remove this depth noise.

We start from the intuitive idea of proportions, derive CPM, log1p, then advance to Pearson residuals which use the negative binomial model to jointly remove the mean-variance relationship. Every step has an interactive visualization.

📍 在 scRNA-seq 流程中的位置

📍 Position in scRNA-seq pipeline

QC (M2.1) →QC (M2.1) → 【normalize：消除測序深度差異 (本章)】 → HVG (M2.3) → scale (M2.4) → PCA (M3.1) → ...

⚠️ 沒 normalize，PC1 會抓「哪個 cell 測序深度高」這個無關生物的方向——所有下游發現變廢。 ⚠️ Without normalize, PC1 captures "which cell has higher sequencing depth" — a biology-free direction that ruins all downstream findings.

🎯 為什麼 scRNA-seq 必須 normalize（bulk RNA-seq 也要但問題更小）

🎯 Why scRNA-seq must normalize (bulk also needs but less critical)

  • 細胞間 depth 變異大：10x 一份資料中，total_counts 在 1,500-20,000 之間（10× 變異），bulk RNA-seq 只 ~2× 變異
  • Large cell-to-cell depth variation: in one 10x dataset, total_counts ranges 1,500-20,000 (10× variation); bulk RNA-seq only ~2× variation
  • 原因：droplet 體積差異 + capture efficiency 變異 + cell cycle phase（M phase 有更多 mRNA）
  • Causes: droplet volume variation + capture efficiency variation + cell cycle phase (M phase has more mRNA)
  • 後果：兩個完全一樣的 T 細胞，一個 total=2000, 另一個 total=8000 → raw counts 全差 4 倍 → 看起來像不同 cell type
  • Consequence: two identical T cells, one total=2000, other total=8000 → raw counts differ 4× → appear as different types

§1 Size factor 的直覺Size factor intuition

「除以 total」可以看成「除以一個 size factor $s_i$」。最簡單的選擇 $s_i = \text{total}_i$。

"Dividing by total" generalizes to dividing by a size factor $s_i$. Simplest: $s_i = \text{total}_i$.

$$\tilde{x}_{ij} = \frac{x_{ij}}{s_i}$$
$x_{ij}$ = cell $i$ 中 gene $j$ 的原始 count
$x_{ij}$ = raw count of gene $j$ in cell $i$

§2 CPM / CP10K：第一個合理公式CPM / CP10K: first reasonable formula

$\tilde{x}_{ij}$ 是極小比例，乘上常數 $K$ 比較好讀。bulk RNA-seq 用 $K=10^6$（CPM）；scRNA 因計數少改用 $K=10^4$（CP10K）。

$\tilde{x}_{ij}$ is tiny — multiply by $K$ for readability. Bulk uses $K=10^6$ (CPM); scRNA uses $K=10^4$ (CP10K).

$$\text{CP10K}_{ij} = \frac{x_{ij}}{s_i} \times 10^4, \quad s_i = \sum_j x_{ij}$$

2.1 數字檢驗

2.1 Number check

cell A：CD3D=40, total=8000 → CP10K = 40/8000×10000 = 50。
cell B：CD3D=10, total=2000 → CP10K = 10/2000×10000 = 50。一致。

cell A: 40/8000×10000 = 50. cell B: 10/2000×10000 = 50. Match.

K 的選擇Careful with K: K 只影響「數字尺度」不影響「比例關係」。K=10K vs 1M 數學等價，但 K=10K 配合 log1p 後 0 不會被誇大。 $K$ only sets scale, not ratios. K=10K vs 1M are mathematically equivalent, but K=10K avoids inflating 0s after log1p.

§3 為什麼 log1p？— 變異穩定化 + 處理 0Why log1p? variance stabilization + handling 0

3.1 理由一：變異穩定化

3.1 Reason 1: variance stabilization

Poisson 變異 $\text{Var}(X) = \mu$——高表現基因的變異本來就大，PCA 會被高表現綁架。log 把這拉直：

Poisson variance $\text{Var}(X)=\mu$ — high-expr genes have inherently large variance, hijacking PCA. Log straightens:

$$\text{Var}(\log X) \approx \frac{\text{Var}(X)}{\mu^2} = \frac{\mu}{\mu^2} = \frac{1}{\mu}$$
delta 法：log 後變異隨平均「遞減」
delta method: post-log variance decreasing in mean

所以 log(CPM) 在「中-高表現」變異較均勻，PCA 不再被高表現綁架。

log(CPM) has more uniform variance across mid-high expression — PCA freed from high-expr genes.

3.2 理由二：處理 0

3.2 Reason 2: handling 0

$\log 0 = -\infty$。用 $\log(1+x)$ 代替——這就是 log1p。

$\log 0 = -\infty$. Use $\log(1+x)$ — this is log1p.

$$\text{logCP10K}_{ij} = \log\!\left(1 + \frac{x_{ij}}{s_i} \cdot 10^4\right)$$
▸ 為什麼 +1 不會破壞數學 ▸ Why "+1" doesn't break the math

大 $x$ 時 $\log(1+x) \approx \log x$。$x=0$ 時 $\log(1+0)=0$。所以加 1 只在「接近 0」處有實質效果——恰好就是我們要的。

For large $x$, $\log(1+x)\approx\log x$. For $x=0$, $\log(1+0)=0$. The "+1" only matters near 0 — exactly where we want it.

§5 負二項與 Pearson Residuals（scTransform）NB model and Pearson Residuals (scTransform)

log(CP10K+1) 有結構缺陷：低表現基因的變異還是太大（log 變異穩定化在 $\mu \to 0$ 失效）。 Pearson residuals（Hafemeister & Satija 2019，scTransform）用 NB 模型，把「平均-變異關係」整個吸收。

log(CP10K+1) has a structural flaw: low-expression genes still have inflated variance (the log variance-stabilization fails as $\mu \to 0$). Pearson residuals (Hafemeister & Satija 2019) use NB to absorb the full mean-variance relationship.

5.1 為什麼 scRNA-seq 是 NB 而非 Poisson？

5.1 Why scRNA-seq is NB, not Poisson?

Poisson 假設 mean = variance。但實測 scRNA-seq 變異總是 > mean——這叫 overdispersion。NB 用離散度參數 $\theta$ 處理：

Poisson assumes mean=variance. Empirically, scRNA-seq variance is always > mean — overdispersion. NB adds $\theta$:

$$X \sim \text{NB}(\mu, \theta) \quad\Longrightarrow\quad E[X]=\mu, \quad \text{Var}(X)=\mu + \frac{\mu^2}{\theta}$$
$\theta \to \infty$ 退回 Poisson；$\theta$ 越小越 overdispersed
$\theta \to \infty$ recovers Poisson; smaller $\theta$ = more overdispersion

5.2 Pearson Residual 定義

5.2 Pearson Residual definition

$$z_{ij} = \frac{x_{ij} - \mu_{ij}}{\sqrt{\mu_{ij} + \mu_{ij}^2 / \theta_j}}$$
「觀察 − 預期」除以 NB 模型的 σ
"observed − expected" divided by NB-modeled SD

其中 $\mu_{ij}, \theta_j$ 由每基因 fit GLM 得到：

where $\mu_{ij}, \theta_j$ come from fitting a GLM per gene:

$$\log \mu_{ij} = \beta_{0,j} + \beta_{1,j} \log s_i$$
基因 $j$ 的 mean 隨細胞 depth 的對數遞變
gene $j$'s mean varies log-linearly with cell depth
直覺Intuition: Pearson residual 是「比預期高/低幾個 NB-σ?」——所有基因的 residual 變異被打平成 ~1，PCA 不再被任何基因綁架。 Pearson residual asks: "how many NB-σ above/below expected?" — variances flatten to ~1 across all genes; PCA freed.

§7 為什麼 normalization 影響 PCA 結果Why normalization changes PCA result

Normalization 不是裝飾，它直接決定 PCA 找到的方向。

Normalization isn't cosmetic — it determines which directions PCA finds.

不 normalize 的災難

The "no normalization" disaster

假設 5% 的細胞高 depth、95% 低 depth。PCA 的「最大變異方向」會是「所有基因都同步上下」——這個方向只反映 depth，沒有任何生物資訊。PC1 整個被 depth 綁架。

§10 深入：Analytic Pearson Residuals（Lause 2021）— 為何 sctransform 可以省 GLMDeep dive: Analytic Pearson Residuals (Lause 2021) — why sctransform can skip GLM

scTransform 對每個 gene fit 一個 NB GLM，慢且不穩。Lause, Berens & Kobak (2021) 發現： 在合理假設下，Pearson residuals 有閉式解，不需要 GLM fitting！這就是 analytic_pearson。

scTransform fits an NB GLM per gene — slow and unstable. Lause, Berens & Kobak (2021) showed: under reasonable assumptions, Pearson residuals have a closed-form solution — no GLM needed! This is analytic_pearson.

10.1 假設與簡化

10.1 Assumptions and simplification

假設：gene $j$ 跟 cell $i$ 的 expected count 是 $\mu_{ij} = s_i \cdot p_j$，其中 $s_i$ = cell total counts、$p_j$ = gene 全域比例：

Assume: expected count for gene $j$ in cell $i$ is $\mu_{ij} = s_i \cdot p_j$, where $s_i$ = cell total counts, $p_j$ = global gene proportion:

$$\hat{\mu}_{ij} = \frac{x_{i+} \cdot x_{+j}}{x_{++}}, \quad z_{ij} = \frac{x_{ij} - \hat{\mu}_{ij}}{\sqrt{\hat{\mu}_{ij} + \hat{\mu}_{ij}^2/\theta}}$$
$x_{i+}$ = cell sum、$x_{+j}$ = gene sum、$x_{++}$ = grand total（一行算出）
$x_{i+}$ = cell sum, $x_{+j}$ = gene sum, $x_{++}$ = grand total (one-line compute)

$\theta$ 是常數（不依賴 gene），通常設 100。比 scTransform 快 100×，記憶體少 10×。

$\theta$ is constant (gene-independent), typically 100. 100× faster than scTransform, 10× less memory.

§11 替代方法：scran deconvolution（Lun 2016）為何能避開高表現基因綁架Alternative: scran deconvolution (Lun 2016) avoids high-expr gene hijack

「size factor = total counts」會被少數高表現基因影響：若某 gene（如 ALB 在 liver）佔 cell 40% reads，整個 size factor 都跟著它走。 Lun et al. (2016) 提出「pooling deconvolution」解決這個問題。

"size factor = total counts" gets influenced by a few high-expression genes: if one gene (e.g., ALB in liver) makes 40% of a cell's reads, the size factor tracks it. Lun et al. (2016) proposed "pooling deconvolution" to solve this.

11.1 核心想法：池內加總，分解出個別 size factor

11.1 Core idea: sum within pool, deconvolve to individual

  1. 隨機把細胞分成 pool（每 pool ~50 細胞） Randomly group cells into pools (~50 cells each)
  2. 對每 pool 算「池內總 counts」，跟「全資料 reference」算 ratio：$\theta_p = \sum_{i \in p} s_i / \sum_i s_i$ For each pool: ratio of "pool total counts" to "global reference": $\theta_p = \sum_{i \in p} s_i / \sum_i s_i$
  3. 線性方程組求解每 cell 的 $s_i$： Linear system to solve per-cell $s_i$: $\theta_p = \sum_{i \in p} s_i$
  4. 用多個 overlapping pools over-determined → 最小平方解 Many overlapping pools → over-determined → least squares
為什麼 pool 比 individual 穩Why pool beats individual: 單一 cell 受少數高表現 gene 影響大；pool 50 個 cells 後，這些高表現 gene 「被平均掉」，pool 總和更能反映 depth 而非 biology。實測對 brain / liver / muscle 等「強 marker」組織明顯改善。 A single cell is dominated by a few high-expr genes; pooling 50 cells averages them out, the pool total reflects depth rather than biology. Empirically better for "strong marker" tissues like brain / liver / muscle.

§12 GLM-PCA（Townes 2019）：跳過 normalize 直接 PCA on raw countsGLM-PCA (Townes 2019): skip normalize, PCA on raw counts directly

Townes et al. (2019) 提出 GLM-PCA：原 PCA 假設資料是 Gaussian，所以要先 normalize 把 count 變 Gaussian-like； 那如果用 NB likelihood 當「PCA loss」就可以直接在原始 count 上做 PCA！

Townes et al. (2019) proposed GLM-PCA: classical PCA assumes Gaussian data, so we normalize first; use NB likelihood as the "PCA loss" instead, and you can PCA on raw counts directly!

$$\text{maximize: } \log P(X | UV^T), \quad X_{ij} \sim \text{NB}(\mu_{ij}, \theta), \quad \log \mu_{ij} = (UV^T)_{ij} + s_i$$
$U \in \mathbb{R}^{n \times k}$ = cell factors、$V \in \mathbb{R}^{p \times k}$ = gene factors，$s_i$ 是 size offset
$U$ = cell factors, $V$ = gene factors, $s_i$ is size offset
