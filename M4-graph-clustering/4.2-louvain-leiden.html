Louvain 與 Leiden 演算法

Louvain & Leiden

Modularity 在優化什麼？Louvain 的「斷裂群」問題與 Leiden 如何修。resolution 參數的數學意義。

What modularity optimizes. Louvain's "disconnected community" bug and Leiden's fix. The math of resolution.

直覺 / Intuition

「好的分群」= 群內連接多、群外連接少。Modularity 把這件事量化成一個數字，讓我們可以「優化它」。

"Good clustering" = many within-edges, few between-edges. Modularity quantifies this for optimization.

核心數學 / Math

Modularity

$$Q = \frac{1}{2m} \sum_{i,j} \left[ A_{ij} - \gamma \frac{k_i k_j}{2m} \right] \delta(c_i, c_j)$$
$A_{ij}$ = 邊權重；$k_i$ = 節點度數；$m$ = 邊總權重；$\gamma$ = resolution；$\delta(c_i, c_j)=1$ 若同群
$A_{ij}$ = edge weight; $k_i$ = degree; $m$ = total weight; $\gamma$ = resolution; $\delta=1$ if same cluster

解讀：「實際邊權重」− 「在隨機圖中的期望邊權重」。Q 越大表示分群越「不像隨機」。

Interpretation: "actual edge weight" minus "expected in random graph". Larger Q = clustering further from random.

resolution 參數 γ

Resolution parameter γ

  • $\gamma > 1$：對「隨機期望」加重——只接受很顯著的群 → 較多、較小的群
  • $\gamma < 1$：放寬期望 → 較少、較大的群
  • $\gamma = 1$：原始 Newman-Girvan modularity
  • $\gamma > 1$: stricter random penalty → more, smaller clusters
  • $\gamma < 1$: relaxed → fewer, larger clusters
  • $\gamma = 1$: original Newman-Girvan

scRNA-seq 常用 0.5–1.5，但「正確 resolution」需要生物學判斷。

scRNA-seq typical range 0.5–1.5; "correct" choice requires biological judgment.

Louvain 演算法algorithm

# Two-phase iterative while Q improves: # Phase 1: local moving for v in nodes (random order): c* = argmax ΔQ(move v to c) assign v to c* # Phase 2: aggregation contract each community to a single super-node new edges = sum of inter-community weights
⚠️ Louvain 的 bug：斷裂群 ⚠️ Louvain bug: disconnected communities

Phase 1 可能讓「群 c 中的關鍵節點」移走，剩下的節點被分成兩個實際斷開的子圖——但 Louvain 不會察覺！這在 scRNA-seq 大數據集很常見。

Phase 1 may remove a "bridge node", leaving a community split into actually disconnected subgraphs — Louvain doesn't notice! Common in large scRNA-seq data.

Leiden 的修正fix

在 Phase 1 與 Phase 2 之間插入 refinement phase：把每個群拆成「保證連通」的子群，再聚合。

Insert a refinement phase between Phase 1 and 2: split each community into guaranteed-connected sub-communities before aggregating.

Traag et al. 2019 證明 Leiden 保證：(1) 所有群連通；(2) 每個節點都「最佳對應」其群。現在所有主流 scRNA-seq 工具預設都是 Leiden。

Traag et al. (2019) prove: (1) all communities connected; (2) every node "optimally assigned". All modern tools default to Leiden now.

程式碼 / Code 
sc.tl.leiden(adata, resolution=1.0, random_state=42)
sc.pl.umap(adata, color="leiden")

# 試多種 resolution
for r in [0.5, 0.8, 1.0, 1.5]:
    sc.tl.leiden(adata, resolution=r, key_added=f"leiden_r{r}")

pbmc <- FindClusters(pbmc, resolution = 0.5, algorithm = 4)
# algorithm = 4 是 Leiden；預設 1 是 Louvain
