計數分布：Poisson · NB · ZINB

Count Distributions: Poisson · NB · ZINB

為什麼 scRNA-seq 不能假設高斯分布？三大計數分布的數學本質與適用情境。

Why Gaussian fails for scRNA-seq. The math of three fundamental count distributions.

直覺 / Intuition

計數資料的三個怪癖

Three quirks of count data

scRNA-seq 量到的是「分子數」——只能是 0, 1, 2, ...（不會是 3.7 個分子）。 這帶來三個高斯分布處理不了的特性：

  1. 離散值：只能取整數
  2. 非負：機率質量集中在 0 附近、有「零膨脹」
  3. 變異隨平均放大：高表現基因的變異天然較大

所以我們需要計數分布來建模——這節介紹三個由簡入深的選擇。

scRNA-seq measures molecule counts — only 0, 1, 2, ... (never 3.7 molecules). Three properties Gaussian cannot handle:

  1. Discrete: integers only
  2. Non-negative: probability mass near 0, with "zero inflation"
  3. Variance scales with mean: highly expressed genes have inherently higher variance

We need count distributions — three increasingly sophisticated choices.

核心數學 / Math

① Poisson — 最簡單的計數分布— Simplest Count Distribution

$$P(X = k \mid \lambda) = \frac{\lambda^k e^{-\lambda}}{k!}, \quad k = 0, 1, 2, \ldots$$

關鍵性質：$E(X) = \mathrm{Var}(X) = \lambda$（平均 = 變異）。
這代表「均值決定變異」——一個參數搞定一切。
生物意義：若 RNA 分子捕捉是純隨機事件，理論上應該服從 Poisson。

Key property: $E(X) = \mathrm{Var}(X) = \lambda$ (mean = variance).
Means "mean determines variance" — one parameter does everything.
Biology: if mRNA capture were purely random, it should follow Poisson.

⚠️ 但實際資料的變異遠大於平均！ ⚠️ But real data has much larger variance than mean!

這稱為過度離散 (overdispersion)。原因是不同細胞之間的「真實表現量」本身就有變異（生物變異 + 技術偏差），不只是 Poisson 的隨機取樣噪音。

This is called overdispersion. Different cells have varying "true expression" (biological + technical noise), not just Poisson sampling.

② Negative Binomial (NB) — 加入過度離散— Adding Overdispersion

把 Poisson 的 $\lambda$ 視為「隨機變數」，假設它服從 Gamma 分布，混合之後就得到 NB：

Treat Poisson's $\lambda$ as a random variable from a Gamma distribution; the mixture is NB:

$$P(X = k \mid \mu, \theta) = \binom{k + \theta - 1}{k} \left(\frac{\theta}{\theta + \mu}\right)^\theta \left(\frac{\mu}{\theta + \mu}\right)^k$$ $$E(X) = \mu, \quad \mathrm{Var}(X) = \mu + \frac{\mu^2}{\theta}$$
$\mu$ = 平均、$\theta$ = 分散參數（越大越接近 Poisson、越小越離散）
$\mu$ = mean, $\theta$ = dispersion (larger → closer to Poisson; smaller → more overdispersed)

當 $\theta \to \infty$，$\mathrm{Var} \to \mu$，退化為 Poisson。
典型 scRNA-seq 基因 $\theta \approx 1\text{--}10$，變異是平均的好幾倍。

As $\theta \to \infty$, $\mathrm{Var} \to \mu$, reducing to Poisson.
Typical scRNA-seq genes have $\theta \approx 1\text{--}10$, variance several times the mean.

③ Zero-Inflated NB (ZINB) — 再多解決「過多的零」— Modeling Excess Zeros

有時候 NB 還是低估了 0 的數量（特別是 droplet-based 平台）。ZINB 多加一個「dropout 機率 $\pi$」：

Sometimes NB still underestimates zeros (especially droplet-based platforms). ZINB adds a dropout probability $\pi$:

$$P(X = k) = \begin{cases} \pi + (1-\pi) \cdot \text{NB}(0 \mid \mu, \theta) & k = 0 \\ (1-\pi) \cdot \text{NB}(k \mid \mu, \theta) & k > 0 \end{cases}$$

解讀：
• $\pi$ = 「結構性零」的比例（捕捉失敗、技術 dropout）
• $1-\pi$ = 「真實計數」遵循 NB
scVI、scVAE 等深度模型常用 ZINB 作為 decoder 的 likelihood。

Interpretation: $\pi$ = fraction of "structural zeros" (technical dropouts), $1-\pi$ follows NB. scVI, scVAE use ZINB as decoder likelihood.

🔬 ZINB 真的有必要嗎？爭議所在 🔬 Is ZINB really needed? The controversy

Svensson (2020) 與 Townes et al. (2019) 顯示：對於 UMI-based scRNA-seq（10x），NB 已經足夠，加 zero-inflation 並沒有顯著幫助。爭議至今未完全解決，但目前共識傾向：UMI 用 NB；read-based（Smart-seq2）才考慮 ZINB。

Svensson (2020) and Townes et al. (2019): for UMI-based scRNA-seq (10x), NB suffices; zero inflation doesn't help significantly. Current consensus: use NB for UMI; consider ZINB only for read-based (Smart-seq2).

程式碼 / Code

擬合 NB 到實際資料

Fitting NB to Real Data

import numpy as np
from scipy.stats import nbinom
from scipy.optimize import minimize

# counts: 某個基因在所有細胞的計數
def nb_nll(params, x):
    mu, theta = params
    if mu <= 0 or theta <= 0: return np.inf
    p = theta / (theta + mu)
    return -nbinom.logpmf(x, theta, p).sum()

mu0, theta0 = counts.mean(), 2.0
res = minimize(nb_nll, [mu0, theta0], args=(counts,), method="Nelder-Mead")
mu_hat, theta_hat = res.x
print(f"μ̂ = {mu_hat:.3f}, θ̂ = {theta_hat:.3f}")

# 判斷是否過度離散
print(f"Variance / Mean = {counts.var() / counts.mean():.2f}")
# > 1 表示過度離散，Poisson 不夠

library(MASS)

# fitdistr 直接擬合 NB
fit <- fitdistr(counts, "negative binomial")
mu_hat <- fit$estimate["mu"]
size_hat <- fit$estimate["size"]   # size = theta

cat(sprintf("μ̂ = %.3f, θ̂ = %.3f\n", mu_hat, size_hat))

# 過度離散測試 (likelihood ratio)
library(pscl)
odTest(glm.nb(counts ~ 1))
