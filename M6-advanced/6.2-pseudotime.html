Pseudotime · DPT & Slingshot

Pseudotime · DPT & Slingshot

如何從 snapshot 資料推估時間順序？DPT 的擴散距離、Slingshot 的 principal curves、PAGA 圖簡化。

Inferring temporal order from snapshot data. DPT diffusion distance, Slingshot principal curves, PAGA.

直覺 / Intuition

細胞發育是連續過程：幹細胞 → 中間態 → 成熟態。實驗只能拍「快照」，但發育中的細胞混在一起。Pseudotime 就是要從這個混雜快照重建出時間順序。

Differentiation is continuous: stem → intermediate → mature. Snapshots capture mixed states. Pseudotime reconstructs temporal order.

核心數學 / Math

① DPT (Diffusion Pseudotime) — Haghverdi 2016

建立在 Diffusion Maps 之上。給定 root cell $x_r$，pseudotime 是擴散距離：

Built on Diffusion Maps. Given root cell $x_r$, pseudotime is diffusion distance:

$$\text{dpt}(x_r, x_i) = \|\Psi_t(x_r) - \Psi_t(x_i)\|$$

用「累積轉移機率矩陣」$M = \sum_{t=1}^{\infty} (T - \mathbf{1}\boldsymbol{\pi}^\top)^t$ 算更穩定。

Numerically stabilized via cumulative transition matrix $M$.

② Slingshot — principal curves

兩階段：

Two stages:

  1. 骨幹圖：對 cluster 質心做最小生成樹 (MST)，找分歧點
  2. Principal curves：對每條 lineage 擬合「平滑曲線」
    $\mathbf{f}: [0, 1] \to \mathbb{R}^d$ 最小化 $\sum_i \|x_i - \mathbf{f}(\lambda_i)\|^2$，其中 $\lambda_i$ 是 $x_i$ 在曲線上的投影位置
  1. Skeleton: MST on cluster centroids, find branching
  2. Principal curves: smooth $\mathbf{f}: [0,1] \to \mathbb{R}^d$ minimizing $\sum_i \|x_i - \mathbf{f}(\lambda_i)\|^2$

Pseudotime = 投影位置 $\lambda_i$。優點：能明確處理 lineage 分支。

Pseudotime = projection $\lambda_i$. Handles branching explicitly.

③ PAGA — Wolf 2019

把細胞分群後，把「群與群之間的連通性」量化為圖。簡化複雜流形成可解讀的拓撲圖。

Cluster cells, quantify "connectivity between groups" into a simplified graph topology.

$$w_{kl} = \frac{|E(C_k, C_l)|}{E_{\text{expected}}(C_k, C_l)}$$

$E(C_k, C_l)$ = 跨 cluster 邊數；分母 = 隨機期望邊數。權重 > 1 表示連結比隨機強。

$E(C_k, C_l)$ = inter-cluster edges; denominator = random expectation. Weight > 1 → stronger than chance.

⚠️ Pseudotime 的詮釋陷阱⚠️ Interpretation pitfalls

(1) 不是真實時間——只是「順序」；(2) 對 root cell 選擇敏感；(3) 不同方法結果可能差很多（Saelens et al. 2019 benchmarked >30 methods）。

(1) Not real time — only order; (2) Sensitive to root choice; (3) Methods disagree (Saelens et al. 2019 benchmarked 30+).

程式碼 / Code 
# DPT
sc.tl.diffmap(adata)
adata.uns["iroot"] = np.flatnonzero(adata.obs["cell_type"] == "stem")[0]
sc.tl.dpt(adata)
sc.pl.umap(adata, color="dpt_pseudotime")

# PAGA
sc.tl.paga(adata, groups="leiden")
sc.pl.paga(adata)

library(slingshot)
sce <- slingshot(sce, clusterLabels = "leiden", reducedDim = "UMAP",
                start.clus = "stem")
slingPseudotime(sce)
