Pseudotime：把細胞排成分化軌跡

Pseudotime: ordering cells along differentiation trajectories

Leiden 把細胞分群——但「分化」是連續的。 幹細胞 → 早期 progenitor → 中期 → 晚期 → 成熟細胞，沒有明確的群邊界。 硬分群會丟失「時間軸」這個重要訊號。

Pseudotime 給每個細胞一個「沿軌跡的位置」（0 = 起點、1 = 終點）， 不需要實驗時間資料，純從表現量距離結構推。 本節從 DPT 的 diffusion map 推導出發，介紹 Slingshot 主曲線、Monocle3 partition graph， 最後談 RNA velocity 提供方向資訊。
Leiden gives discrete clusters — but differentiation is continuous. Stem → early progenitor → mid → late → mature: no sharp boundaries. Hard clustering loses the time axis.

Pseudotime assigns each cell a position along the trajectory (0 = origin, 1 = end), without experimental timing — purely from expression distance structure. Starting from DPT's diffusion map derivation, we cover Slingshot's principal curves, Monocle3's partition graph, and finally RNA velocity for directionality.

§0 故事：分化是連續的Story: differentiation is continuous

造血系統是教科書例子：HSC（造血幹細胞）→ MPP → CMP → GMP → 單核球。 每階段表現量緩慢改變，沒有「跳躍」。 你用 Leiden 把細胞分成 5 群——但其實它們沿一條線連續排列。 cluster 邊界是人為切的，不對應任何生物學現實。

Hematopoiesis is the textbook example: HSC → MPP → CMP → GMP → monocyte. Each stage's expression changes gradually, no "jumps". Leiden gives 5 clusters — but cells actually form a continuous line. Cluster boundaries are artificial, with no biological meaning.

§0-1 同樣的細胞：cluster 視角 vs pseudotime 視角

§0-1 Same cells: cluster vs pseudotime view

直覺Intuition: cluster 視角告訴你「有哪些身份」；pseudotime 視角告訴你「過程怎麼進行」。後者讓你能找沿軌跡逐漸開關的 gene——transcription factor、分化決定因子。 Cluster view = "what identities"; pseudotime view = "how the process unfolds". The latter reveals genes that gradually turn on/off along the trajectory — transcription factors, fate determinants.

§2 DPT (Diffusion Pseudotime) 數學DPT math

DPT（Haghverdi et al. 2016）核心想法：把細胞當圖節點，定義「隨機漫步從 root 細胞走到每個細胞的期望時間」當 pseudotime。

DPT (Haghverdi et al. 2016) core idea: treat cells as graph nodes, define pseudotime as the expected random-walk time from a root cell to each other cell.

2.1 三步驟

2.1 Three steps

  1. 建轉移矩陣：Build transition matrix: $T_{ij} = K(x_i, x_j) / \sum_l K(x_i, x_l)$（Gaussian kernel + normalize）
  2. 對 $T$ 做特徵分解：Eigen-decompose $T$: $T = \Phi \Lambda \Phi^{-1}$
  3. DPT 距離 = 在 diffusion space 的歐式距離： DPT distance = Euclidean in diffusion space:
$$\text{dpt}(i, j) = \sqrt{\sum_{k \ge 1} \left(\frac{\lambda_k}{1 - \lambda_k}\right)^2 (\phi_k(i) - \phi_k(j))^2}$$
$\phi_k, \lambda_k$ 是轉移矩陣 $T$ 的第 $k$ 個特徵向量 / 值
$\phi_k, \lambda_k$ are $T$'s $k$-th eigenvector / eigenvalue

給定 root 細胞 $i_0$，每細胞的 pseudotime = $\text{dpt}(i_0, i)$。

Given root cell $i_0$, each cell's pseudotime = $\text{dpt}(i_0, i)$.

2.2 為什麼用 diffusion 距離?

2.2 Why diffusion distance?

關鍵Key: 歐氏距離只看「直線距離」會被噪音影響。Diffusion 距離考慮「所有可能路徑」的權重—— 兩細胞有多條短路徑連通 → DPT 近；只有一條長路徑 → DPT 遠。對軌跡上彎曲、複雜分支特別有效。 Euclidean is noise-sensitive (straight-line). Diffusion considers all paths weighted — two cells with many short paths between them → DPT close; single long path → DPT far. Excellent for curved or branching trajectories.

§4 Slingshot：主曲線擬合Slingshot principal curves

Slingshot（Street et al. 2018）走完全不同路徑：先用 Leiden 找 cluster，再構造 cluster 連通的最小生成樹（MST）， 最後在每條 lineage 上擬合主曲線（principal curve）。

Slingshot (Street et al. 2018) takes a different path: Leiden first to find clusters, then build a cluster MST (minimum spanning tree), finally fit a principal curve along each lineage.

4.1 三步驟

4.1 Three steps

  1. cluster MST：用 cluster centroid 算距離 → 最小生成樹找 lineage 拓樸 cluster MST: distance between cluster centroids → MST gives lineage topology
  2. 主曲線擬合：對每條從 root 到 leaf 的 lineage，擬合一條「平滑曲線」穿過 cluster centroids Principal curve fitting: fit smooth curve through cluster centroids from root to leaf
  3. 細胞投影：每細胞投影到最近曲線，取投影位置當 pseudotime Cell projection: project each cell onto nearest curve, use position as pseudotime
優勢Advantages: 直接利用 cluster 結構 → 對分支軌跡（Y 型、多分支）很穩健。比 DPT 更「實用」。 Leverages cluster structure → robust on branching trajectories (Y, multi-branch). More "practical" than DPT.

§5 Monocle3：partition graphMonocle3 partition graph

Monocle3（Cao et al. 2019）支援多斷裂、多分支的軌跡：用 UMAP 嵌入後，構造 partitioned principal graph。 允許多個獨立軌跡（如不同 lineage）+ 一個軌跡內多個分支。

Monocle3 (Cao et al. 2019) supports disjoint, multi-branch trajectories: build partitioned principal graph on UMAP. Allows multiple independent trajectories (e.g., distinct lineages) + multiple branches within each.

5.1 SimplePPT 演算法

5.1 SimplePPT algorithm

Monocle3 內部用 SimplePPT (simple principal tree)：在 UMAP 上找一棵樹結構，最小化「細胞到樹的距離 + 樹的長度」。 數學上是一個 reversed graph embedding 問題。

Internally uses SimplePPT (simple principal tree): find a tree on UMAP minimizing "cell-to-tree distance + tree length". Mathematically a reversed graph embedding problem.

§6 RNA velocity 提供方向RNA velocity for direction

DPT / Slingshot / Monocle3 都假設「root 由人指定」。但實際分化方向是哪邊？ RNA velocity（La Manno et al. 2018）利用 spliced vs unspliced mRNA 比例推斷 gene 的「未來表現量變化方向」， 再用 cell-level 平均得到「細胞分化方向向量」。

DPT / Slingshot / Monocle3 all assume "root specified by user". But which direction is differentiation actually going? RNA velocity (La Manno et al. 2018) uses spliced vs unspliced mRNA ratios to infer each gene's "future expression direction", then cell-level averaging gives per-cell direction vectors.

6.1 核心方程

6.1 Core equation

$$\frac{ds(t)}{dt} = \beta \cdot u(t) - \gamma \cdot s(t)$$
$u$ = unspliced mRNA、$s$ = spliced mRNA、$\beta$ = splicing rate、$\gamma$ = degradation rate
$u$ = unspliced, $s$ = spliced, $\beta$ = splicing rate, $\gamma$ = degradation rate

velocity = $u - \gamma s$（線性近似）。正 → gene 正在增加；負 → 正在減少。

Velocity = $u - \gamma s$ (linear approx). Positive → gene rising; negative → falling.

為什麼有用Why useful: 不需人類給 root，每細胞自己「指向未來」。整個 UMAP 上的箭頭組成velocity field——告訴你軌跡的真實方向。 No human-defined root; each cell "points toward future". Combined arrows on UMAP form a velocity field — reveals true trajectory direction.
