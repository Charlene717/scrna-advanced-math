CellChat 細胞通訊

CellChat: Cell-Cell Communication

怎麼把基因表現量轉成「通訊機率」？Hill function、permutation test、與其他工具 (CellPhoneDB) 的差別。

Turning expression into "communication probability". Hill function, permutation tests, vs CellPhoneDB.

直覺 / Intuition

細胞之間透過「ligand-receptor 配對」溝通：A 細胞分泌 ligand → B 細胞表面 receptor 接收。要量化「A → B 用 pathway P 通訊的強度」，我們需要：(1) 已知 L-R 對的資料庫；(2) 把 A 的 ligand 表現量 + B 的 receptor 表現量轉成一個機率。

Cells communicate via ligand-receptor pairs: cell A secretes ligand, cell B's receptor receives. Need: (1) curated L-R database; (2) function to combine A's ligand + B's receptor into probability.

核心數學 / Math

通訊機率公式

Communication probability

$$P_{i \to j}^{LR} = \frac{L_i \cdot R_j}{K_h + L_i \cdot R_j}$$
Hill function 形式，$K_h$ 是 half-saturation 常數
Hill function, $K_h$ = half-saturation constant

$L_i$ = cluster $i$ 平均 ligand 表現、$R_j$ = cluster $j$ 平均 receptor 表現。Hill function 是飽和曲線——表現量低時近 0、高時近 1。

$L_i$ = ligand mean in cluster $i$, $R_j$ = receptor mean in $j$. Hill saturates: ~0 at low, ~1 at high.

考慮 cofactor / agonist / antagonist

$$P_{i \to j}^{LR} = \frac{L_i \cdot R_j \cdot (1 + AG_i)^{n}}{K_h + L_i \cdot R_j \cdot (1 + AN_j)^{n}}$$

$AG$ 是 agonist（增強）、$AN$ 是 antagonist（抑制）。CellChat 的 L-R 資料庫已包含這些 cofactor 資訊。

$AG$ enhances, $AN$ inhibits. CellChat's L-R database includes cofactors.

Permutation test 找顯著通訊

Permutation test for significance

# Null hypothesis: cluster identities are random for r in range(1000): shuffled_labels = random.permutation(cluster_labels) P_null[r] = compute_probability(L, R, shuffled_labels) p_value = mean(P_null >= P_observed)

Pathway 層級聚合

Pathway aggregation

$$P_{i \to j}^{\text{pathway}} = \sum_{LR \in \text{pathway}} P_{i \to j}^{LR}$$

同一 pathway 內多個 L-R 對加總，得到 pathway 層級通訊強度。

Sum across L-R pairs in same pathway for pathway-level strength.

與 CellPhoneDB 的差別

Vs CellPhoneDB

  • CellPhoneDB：用「平均表現量乘積」+ permutation。簡單但忽略飽和。
  • CellChat：Hill function + cofactor，更生物學。多種「通訊角色」分析（sender、receiver、mediator、influencer）。
  • NicheNet：考慮下游轉錄因子訊號傳遞，最接近因果。
  • CellPhoneDB: mean × mean + permutation. Simple, ignores saturation.
  • CellChat: Hill + cofactors, more biological. Multiple roles analysis.
  • NicheNet: includes downstream TF signaling, closest to causality.
程式碼 / Code 
library(CellChat)
cc <- createCellChat(GetAssayData(pbmc, slot="data"),
                     meta=pbmc@meta.data, group.by="cell_type")
setIdent(cc, ident.use="cell_type")
cc@DB <- CellChatDB.human

cc <- subsetData(cc) %>% identifyOverExpressedGenes() %>%
      identifyOverExpressedInteractions()
cc <- computeCommunProb(cc)      # 主要算法
cc <- computeCommunProbPathway(cc)
cc <- aggregateNet(cc)

netVisual_circle(cc@net$weight)
