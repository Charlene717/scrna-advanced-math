CellChat：找細胞間的 ligand-receptor 通訊

CellChat: ligand-receptor cell-cell communication

細胞型態（T cell, B cell, monocyte...）之間並非彼此獨立——它們透過分泌訊號分子 (ligand) 跟其他細胞的 受體 (receptor) 互動。 例如 monocyte 分泌 IL-1β → 在 T cell 上跟 IL1R 結合 → 活化 T cell。

CellChat（Jin et al. 2021）等工具系統化找出：「cluster A 透過 ligand X 跟 cluster B 的 receptor Y 通訊」的所有可能對。 本節從 ligand-receptor database 直覺開始，理解通訊強度的數學（mass action law）， 用 permutation test 篩選顯著通訊，最後比較 CellChat / CellPhoneDB / NicheNet 三大主流工具。
Cell types (T cell, B cell, monocyte...) don't operate independently — they communicate via secreted ligands binding receptors on others. E.g., monocyte secretes IL-1β → binds IL1R on T cell → activates T cell.

CellChat (Jin et al. 2021) systematically finds: "cluster A communicates with cluster B via ligand X → receptor Y" pairs. Starting from L-R database intuition, communication-strength math (mass action law), permutation testing, and finally comparing CellChat / CellPhoneDB / NicheNet.

🧬 scRNA-seq 視角：CellChat 把「單細胞圖譜」變成「細胞社會學」 🧬 scRNA-seq perspective: CellChat turns a "single-cell atlas" into "cellular sociology"

📍 在 scRNA-seq 流程中的位置Position in scRNA-seq pipeline

所有上游（QC → cluster → annotation） → CellChat / CellPhoneDB / NicheNet (L-R signaling) → signaling network → pathway enrichment → spatial validation → drug target

前面所有 scRNA 步驟（QC、normalize、cluster、annotation）都是把細胞分類；CellChat 是第一個把它們連起來的步驟——回答「細胞型態之間怎麼互動」。腫瘤微環境、發育、組織再生、免疫反應的核心 paper 結論都在這層。 All previous scRNA steps (QC, normalize, cluster, annotation) categorize cells; CellChat is the first step that links them together — answering "how cell types interact". Core findings in tumor microenvironment, development, tissue regeneration, immune response papers live at this layer.

🎯 為什麼 scRNA-seq 必須做 cell-cell communication 分析Why scRNA-seq must do cell-cell communication analysis

  • scRNA 一次量全 transcriptome → 同時看 ligand 跟 receptorscRNA measures full transcriptome → ligand + receptor simultaneously： bulk RNA-seq 一次只看一個 tissue 的 mixed signal，沒法問「macrophage 的 IL-1β 跟 T cell 的 IL1R 是不是同時高」；scRNA 給每個 cell type 獨立的 expression profile讓 L-R 配對成為可能。 Bulk RNA-seq sees only mixed-tissue signal, can't ask "is macrophage IL-1β co-expressed with T cell IL1R"; scRNA gives independent expression profiles per cell type, making L-R pairing feasible.
  • 疾病靶點 = 細胞間訊號異常Disease targets = aberrant cell-cell signals： 癌症 immune escape（PD-L1 / PD-1）、慢性發炎（IL-6 / IL-6R）、纖維化（TGFβ）都是cell-cell signaling 異常。CellChat 系統化把這些通訊量化、可比較。 Cancer immune escape (PD-L1 / PD-1), chronic inflammation (IL-6 / IL-6R), fibrosis (TGFβ) are all cell-cell signaling abnormalities. CellChat systematizes these communications, makes them quantifiable and comparable.
  • 跟 spatial transcriptomics 互補Complements spatial transcriptomics： CellChat 給 candidate L-R pair → spatial（Visium / MERFISH）驗證「兩個細胞是否在物理上接觸」→ 形成可信的 signaling map。scRNA 沒有空間訊息，CellChat 提供 candidate 是必要橋樑。 CellChat gives candidate L-R pairs → spatial (Visium / MERFISH) validates "physical contact" → trustworthy signaling map. scRNA lacks spatial info; CellChat-provided candidates are the essential bridge.

Without CellChat, scRNA gives a list of cell types; with CellChat, scRNA gives a relationship network — and the core mechanisms of disease, development, regeneration all live in that network.

§2 通訊強度：mass action lawCommunication strength: mass action

CellChat 用化學的 mass action 定律 估通訊強度。直覺：「分子越多 → 反應越強」。 ligand 量大 × receptor 量大 → 通訊強。

CellChat uses chemistry's mass action law for communication strength. Intuition: "more molecules → stronger reaction". Many ligands × many receptors → strong communication.

2.1 公式

2.1 Formula

$$P_{A \to B}^{L-R} = \frac{L_A \cdot R_B}{K_h + L_A \cdot R_B} \cdot \prod_k \text{cofactor}_k$$
$L_A$ = cluster A 中 ligand 平均表現量、$R_B$ = cluster B 中 receptor 平均表現量、$K_h$ = Hill 常數
$L_A$ = mean ligand in cluster A, $R_B$ = mean receptor in cluster B, $K_h$ = Hill constant

這是 Hill 飽和函數：當 $L_A \cdot R_B \ll K_h$ → 線性；$\gg K_h$ → 飽和到 1。模擬實際酶反應的飽和現象。 $\prod_k \text{cofactor}_k$ 校正 agonist / antagonist 的影響（CellChat 獨有）。

This is a Hill saturation function: when $L_A \cdot R_B \ll K_h$ → linear; $\gg K_h$ → saturates to 1. Mimics enzyme kinetics. $\prod_k \text{cofactor}_k$ adjusts for agonist/antagonist effects (CellChat unique).

§4 Permutation test 篩選顯著通訊Permutation test

算出每對 (cluster A, cluster B, L, R) 的觀察分數。怎麼知道分數高是真實通訊還是純隨機？ 答案：permutation test。

We get observed scores per (cluster A, cluster B, L, R). How to know high score = real communication vs random? Answer: permutation test.

4.1 三步驟

4.1 Three steps

  1. 隨機重新分配細胞 cluster 標籤 → 算分數 $P_{\text{null}}^{(k)}$，重複 1000 次 Randomly shuffle cell cluster labels → compute score $P_{\text{null}}^{(k)}$, repeat 1000 times
  2. p-value = p-value = $\#\{P_{\text{null}}^{(k)} \ge P_{\text{obs}}\} / 1000$
  3. FDR (BH) 篩選 p < 0.05 的 L-R pair FDR (BH) filter L-R pairs with p < 0.05
關鍵直覺Key intuition: 通訊「強」不一定「特異」。permutation test 檢驗「這個分數是不是只有原本 cluster 標籤才會出現」——也就是 cluster identity 真的有影響。 "Strong" communication ≠ "specific". Permutation tests whether "this score is special to the original cluster labels" — confirming cluster identity matters.

§8 NicheNet：把 ligand 連到下游 target genesNicheNet: linking ligand to downstream target genes

CellChat 只告訴你「A 跟 B 通訊」。NicheNet（Browaeys 2020）多一步——「這個 ligand 在 receiver cell 引起哪些 gene 表現變化」。整合 signal transduction → transcription 完整鏈。

CellChat tells you "A talks to B". NicheNet (Browaeys 2020) goes further: "which genes does this ligand induce in receiver cells". Integrates signal transduction → transcription full chain.

8.1 NicheNet 的 prior model

8.1 NicheNet's prior model

NicheNet 預先從文獻、KEGG、Reactome 整合三層權重 graph：

NicheNet pre-integrates three-layer weighted graph from literature, KEGG, Reactome:

  1. Ligand → ReceptorLigand → Receptor
  2. Receptor → signaling pathway components Receptor → signaling pathway components
  3. Signaling → transcription factors → target genes Signaling → TFs → target genes

8.2 工作流程

8.2 Workflow

  1. 輸入：sender cells + receiver cells + receiver cells' DE genes Input: sender cells + receiver cells + receiver's DE genes
  2. 輸出：「最可能 driving」這些 DE 的 ligand list（按 score 排序） Output: ligand list ranked by score for "likely driving these DEs"
  3. + ligand → target gene network + ligand → target gene network
