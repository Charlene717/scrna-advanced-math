Integration · Harmony

Integration · Harmony

為什麼 batch effect 可以在 PCA 空間用「軟分群 + 偏移修正」消除？CCA、MNN、Harmony 的數學。

Why batch effects can be removed in PCA space via "soft clustering + shift correction". The math of CCA, MNN, Harmony.

直覺 / Intuition

不同批次/平台/個體做的 scRNA-seq 會產生「同細胞型態被分成兩堆」的人為效應（batch effect）。整合（integration）就是要消除這個。

核心想法：在低維空間裡，找到「同一細胞型態的不同 batch 細胞」，把它們拉在一起。三大方法用不同數學工具達成這件事。

Different batches/platforms/donors create artifact "same cell type split into two clouds". Integration removes this. Idea: in low-D, find same-type cells across batches and align them.

核心數學 / Math

① CCA (Canonical Correlation Analysis) — Seurat v2/v3

找兩個 batch 投影方向 $\mathbf{u}, \mathbf{v}$，最大化兩 batch 的「典型相關」：

Find projection directions $\mathbf{u}, \mathbf{v}$ maximizing canonical correlation:

$$\max_{\mathbf{u}, \mathbf{v}} \frac{\mathbf{u}^\top \mathbf{X}_1^\top \mathbf{X}_2 \mathbf{v}}{\sqrt{(\mathbf{u}^\top \mathbf{X}_1^\top \mathbf{X}_1 \mathbf{u})(\mathbf{v}^\top \mathbf{X}_2^\top \mathbf{X}_2 \mathbf{v})}}$$

CCA 找出「兩 batch 共有的變異方向」（生物訊號），忽略 batch 專屬變異。

CCA finds shared variation (biology), ignores batch-specific variation.

② MNN (Mutual Nearest Neighbors) — Haghverdi 2018

$$\text{MNN}(i, j) \iff i \in \mathcal{N}_k^{(B_2)}(j) \,\wedge\, j \in \mathcal{N}_k^{(B_1)}(i)$$

細胞 $i$（batch 1）跟細胞 $j$（batch 2）互相是對方的 KNN——它們很可能是同細胞型態。
從 MNN 對計算「校正向量」：$\mathbf{c}_i = \frac{1}{|M_i|}\sum_{j \in M_i} (\mathbf{x}_j - \mathbf{x}_i)$，把 batch 1 拉向 batch 2。

Cells $i$ (batch 1) and $j$ (batch 2) are mutually KNN — likely same cell type. Compute correction vectors $\mathbf{c}_i = \frac{1}{|M_i|}\sum_{j \in M_i} (\mathbf{x}_j - \mathbf{x}_i)$.

③ Harmony — Korsunsky 2019

在 PCA 空間迭代執行兩步：

Iterate two steps in PCA space:

# Step 1: soft clustering (modified k-means) maximize Σ_k Σ_i R_{ik} · ⟨z_i, μ_k⟩ - σ Σ_i,k R_{ik} log R_{ik} # entropy regularization + θ Σ_b Σ_k R_{ik} · I(b_i = b) # diversity penalty # Step 2: linear correction for each cluster k: for each batch b: β_{k,b} = mean_{i ∈ k, batch b}(z_i) - mean_{i ∈ k}(z_i) z_i ← z_i - R_{ik} · β_{k,b_i} # 對每個細胞做加權偏移 # 迭代到收斂

關鍵巧思：「diversity penalty」項 $\theta \sum_b R_{ik} \cdot I(b_i = b)$ 懲罰「某一 cluster 只屬於某一 batch」——強迫每個 cluster 內 batch 比例接近全局比例。
Harmony 的整個算法都是線性的，速度極快（百萬細胞分鐘級）。

Key trick: diversity penalty $\theta \sum_b R_{ik} \cdot I(b_i = b)$ punishes "cluster dominated by one batch", forcing batch ratios to match global. Entire algorithm linear, very fast.

📊 BBKNN — 圖層級整合📊 BBKNN — graph-level integration

不修改 PCA 座標，而是修改 KNN graph：對每個細胞，從每個 batch 各選 $k_{\text{batch}}$ 個近鄰，強迫圖跨 batch 連結。最簡單最快的整合方法。

Doesn't modify PCA coords; instead modifies KNN graph: pick $k_{\text{batch}}$ nearest neighbors per batch for each cell. Forces cross-batch connections.

程式碼 / Code 
import scanpy.external as sce
sce.pp.harmony_integrate(adata, key="batch")
sc.pp.neighbors(adata, use_rep="X_pca_harmony")

# BBKNN
sce.pp.bbknn(adata, batch_key="batch")

library(harmony)
pbmc <- RunHarmony(pbmc, group.by.vars = "batch")
pbmc <- FindNeighbors(pbmc, reduction = "harmony", dims = 1:30)

# Seurat CCA-based
list <- SplitObject(pbmc, split.by = "batch")
anchors <- FindIntegrationAnchors(list, dims = 1:30)
integrated <- IntegrateData(anchors)
